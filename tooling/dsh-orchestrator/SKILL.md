# DSH 协作执行

DSH 是执行工具。Codex 保留任务理解、方案决策、必要的风险判断和最终验收。目标是在满足用户质量要求的前提下减少 Codex 总消耗；不要为了委派而委派，也不要声称一定省额度。

## 连接

首次连接、换电脑、连接失效时，读取 [连接与迁移](references/connection.md)。已有可用连接只做必要状态检查，不重复安装。优先复用用户正在使用的 DSH 桌面模型及项目会话，使用户可见任务指派和回复。只有经过实测的 MCP/API 才可使用；不要凭工具名称推断已经接通。

2026-10-17 的实际基线：macOS DSH 0.2.1-rc.1 桌面 UI 派发和回复已验证，模型显示 DeepSeek-V4.1-Flash。第三方 HTTP 桥直连该桌面返回 401，尚未验证认证兼容；独立运行的旧 MCP 桥不等于桌面实例，其记录不一定出现在桌面。此记录是版本证据，不是其他电脑的安装前提。

## 分流

| 路径 | 判断 | 常见任务 |
| --- | --- | --- |
| Codex 直接做 | 很小、调用开销超过执行成本，或必须由 Codex 决策验收 | 改一句文案、明确答疑、最终质量评判 |
| 直接委派 DSH | 输入、做法与验收明确；操作可隔离、可回退，失败易发现 | 已给定规格的建模、批量格式转换、资产清点、按现成模式做局部修改 |
| Codex 先分析再委派 | 根因不明、跨模块、存在方案选择或质量依赖；执行本身可交付明确任务 | 公共函数修复、持久化修改、复杂场景建模、跨模块重构 |
| 暂缓依赖步骤 | 缺少决定性输入、权限或无法确认状态 | 路径不明、模型费用来源未获授权、破坏性操作待确认 |

分类取决于具体任务，不能把“低质量要求”理解为允许违反约束、丢数据或随意交付。用户未降低标准时仍按原要求验收。复杂工作先检查真实调用链和现成工具，提供选定方案、修改位置、接口契约、边界条件和验收依据，再交 DSH。不要让 Codex 先写完整实现、DSH 机械誊写而造成双重消耗。

## 派发

只给执行所需的上下文，不转发整段聊天或整仓库。用以下紧凑结构，按任务删减：

```text
【Codex 任务指派｜任务名｜唯一标识】
目标：具体交付和用户可观察的结果。
工作目录：本机实际绝对路径；输入与输出位置。
允许修改：文件或目录范围；禁止修改的内容。
已知事实：必要上下文、接口、现有工具及相关仓库规范。
实施方案：简单任务写必要做法；复杂任务写 Codex 已确认的步骤与边界。
验收：能实际检查的结果、运行的已有检查及质量标准。
停止条件：超范围、缺输入、方案不成立或验证失败时，先报告证据，不擅自扩大工作。
返回：完成状态、变更文件/产物、实际验证、未解决问题；避免长篇复述。
```

仓库自己的 AGENTS.md 等约束同样适用于 DSH，显式传递关键限制。代码执行优先使用现成隔离工作区；在有未提交改动的主工作区，不允许覆盖或还原用户改动。只读任务无需新建工作树；建模和媒体任务使用独立输出目录。不要把某台电脑的路径、账户、API key 或旧任务 ID 写成通用默认值。

用户授权 DSH 自主协作后，授权范围内无需逐次询问；授权不扩大任务范围、模型费用或外部发布权限。不要复制凭据来“迁移技能”。

## 跟进与节省消耗

- 用新建的 DSH 桌面项目会话执行，保留会话标题、任务标识及可用的 session/task ID。可在同一任务会话补充指令；不要把无关项目混入长会话。
- 支持异步的桥接先提交后有界等待；桌面操作则观察生成状态和最终回复。轮询逐渐退避，仅在进度、失败、完成或需决定时读取必要信息。不要反复读取完整历史。
- 超时或断线先查询原任务，确认没有执行才决定是否重试。不要重复提交可能产生文件、费用或外部副作用的操作。
- 默认一个执行任务；仅在用户允许、连接支持且目录与任务独立时采用有界并发。不要为分流判断再启动多个 Codex 代理。
- DSH 失败后根据具体证据纠正一次；同类问题仍重复、方案明显不成立或验收成本高于直接修复时，由 Codex 重新判断，停止无效循环。
- 不承诺已结束的 Codex 对话自动被唤醒。需要定时、后台监控或额外集成时按目标环境另行配置。

## 验收与交付

DSH 自报完成只是待验收。Codex 检查实际产物及相关变更范围，并运行与风险匹配的必要验证：代码看关键 diff 和既有类型检查/构建；建模查看工程参数及实际渲染；批处理核对数量、输出格式和代表性内容。高风险或不可逆结果需要更充分验证。遵守仓库关于测试的限制，不为验收擅自新增测试文件。

不重复整套 DSH 执行过程。依据失败现象定向复核，合格后再整合。报告结果、验证依据、剩余限制；`partial`、错误事件或空验收字段不能包装成全面成功。没有真实令牌或费用数据时，不编造节省百分比。
