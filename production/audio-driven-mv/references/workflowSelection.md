# 工作流选择、官方方法与实测边界

## 按任务选路径

| 任务 | 路线 | 输入与检查 |
| --- | --- | --- |
| 已有完整歌曲，人物按原唱对口型 | 默认音乐数字人，当前 h3DigitalHuman | 一张构图图＋实际歌曲音频，普通动作正文；先查配置，保留音频时序 |
| 已录对白、单人讲述 | 实际支持 drivingAudio 的数字人 | 音频必须包含本段真实台词；只有音色样本时先准备实际对白，不能把样本当台词 |
| 多角色对话、只借用音色说新台词 | 全能参考 | 真实人物参考＋音色样本；样本用 reference，不复制样本台词 |
| 白模运动、多图身份、多素材分镜 | 全能参考 | 六段格式；区分身份、场景、构图和视频运动，不把白模声音混入最终歌声 |
| 明确首帧到尾帧的动作 | FL2VA | 两张真实帧，符合当前节点规格；不能只靠尾帧参考承诺严格首帧锁定 |
| 文生、单图、其他关键帧 | 对应 T2VA/I2VA/L2VA 模式 | 使用该模式接受的正文；无驱动音频入口不承诺原唱口型 |
| 视频编辑、视频续接 | 确认支持的编辑或续接模式 | 必须确实编辑或延续源视频，仅借用运镜不称为编辑；分别声明画面与声音作用 |

这些是选择标准，不是把所有任务都转成数字人。用户明确选定的工作流和阶段优先；不可用或不适合时解释具体差异，不静默回退。MV 可以有近景、正面直视、上摇下摇、跟随或多镜切换，按用户意图安排，不能把某段的一镜到底、不看镜头固化为全局规则。

## 实测如何解释

已有样本中，中文六段式成功过，英文六段式也出现过歌词正确但节奏或音高改变；改用音乐数字人、普通英文动作正文后，用户认可了效果。同一原图与原 WAV 的这次对照仍同时改变了工作流、提示词结构和动作约束，不能据此证明语言、格式或关键字位置的独立因果。

成功的数字人提示词没有 fully_copy；全能参考成功和失败样本都在 retention_analysis 使用过 fully_copy。不要编造“必须放首行”或“英文一定更准”的规则。优先匹配驱动能力和输入槽位，把原曲时间关系放在正文开头说明；将动作对齐实际乐句，避免另造与演唱竞争的固定手势时间表。

返回音轨与源音频的归一化波形相关、分窗口时延可辅助检查复制与漂移，压缩编码也会影响指标；这些指标不能单独证明嘴型正确、模型内部驱动机制或完全逐样本复制。外部工作流内部是否分段或重新封装音轨需另有证据。本地没有换轨，只能说明本地未替换，不能推断服务内部实现。

不默认使用付费 A/B 或昂贵的自动识别。用户要验证某一因素时，在同素材、工作流和参数下只改一个变量，多次比较，并核对新增生成授权。

## 官方规则摘要

以下来自全能参考官方指南，适用该模式，不能当成数字人工作流的内部合约：

- 先区分可复用可见主体、帧或构图锚点、视频结构与音频信号；标签全程含义一致。同一视频的画面与声音需要分别表达角色，视频带声音不自动等于声音被启用。
- 音频完整复用用 fully_copy；只复制部分或改混音用 partially_copy；借音色、节奏或声音质感用 reference；仅宽泛氛围用 weak_reference。完整复制不能同时要求另加音效或新配乐。
- 正文用英文，台词、歌词与可见文字保留原语言。可见角色的发声有稳定说话人编号；纯配乐中的歌词线索不凭空增加说话人。
- 镜头描述交代当前构图、主体动作和实际摄影机路径。跨切声音保持同一来源；画面切走并不等于新角色接唱。剪辑点围绕实际乐句和动作安排。
