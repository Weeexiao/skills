# Blender 白模预演

用低精度几何体验证镜头，而不是做最终视觉。适用于短剧、MV、广告等任何"这段走位/运镜到底成不成立"的场景。

## 用途

白模回答的是**物理与构图问题**：

- 人物站位、层次、距离、遮挡关系对不对
- 景别与主体画面大小是否符合分镜
- 行走路径、机位移动会不会穿墙、撞人或穿模
- 动作转折时点与音频对不对得上
- 摄影机朝向与运镜是否如预期

它**不回答**表演问题：人物没有脸，不能验证闭眼、皱眉、嘴型或微表情。

## 触发场景

- "先搭个白模看看这段走位"
- "这个镜头帮我预演一下"
- "运镜会不会穿墙"
- "复杂场面先验证机位再生成"

用户明确说不用白模时不要主动加这一阶段。

## 目录结构

```text
blender-previs/
├── SKILL.md      # 完整流程：搭计划 → 搭建 → 关键帧 → 渲染 → 校准 → 接入 → 验收
└── README.md     # 本文件
```

## 与其他技能的分工

| 需求 | 用哪个 |
| --- | --- |
| 只要验证走位/运镜/时间轴 | 本技能 |
| 要真的把模型做出来、要好看 | `create-3d-model` 及 `blender-modeling` 等内置模块 |
| 只要 H3 提示词结构 | `h3-prompt-writing` |
| 要设计镜头语言 | `minimax-h3-storyboard-director` |
| MV 分段的完整制作链路 | `audio-driven-mv`（其中白模环节调用本技能） |

本技能是 `audio-driven-mv` 白模环节的**规范本体**；MV 侧的音频、唱词与引用编号细节留在 `production/audio-driven-mv/references/blenderPrevis.md`。

## 安装

与合集内其他技能相同，放到运行时的用户级 skills 路径（DSH 为 `~/.agents/skills/`），目录名须与 `SKILL.md` 的 `name` 一致（`blender-previs`）。合集根 README 的单克隆 + 目录联接方案可一次装全。

## 依赖

| 依赖 | 说明 |
| --- | --- |
| Blender 可执行文件 | **硬依赖**。默认取 PATH 中的 `blender`；未在 PATH 时需在 DSH 中配置 `blenderExecutable` 指向实际路径 |
| FFmpeg | 把 PNG 帧序列编码为预演 MP4 |
| Python（bpy） | 由 Blender 自带，无需单独安装 |

缺 Blender 时本技能无法产出预演视频，应直接报告缺项，不要用文字计划或静态图替代"已验证"的结论。

## 关键约定

- **先计划后搭建**：人物/空间/动作/镜头/时间轴五项写清再动手。
- **每段独立场景**，不重置用户整个 Blender 文件。
- **PNG 序列 + FFmpeg 编码**，不依赖特定 Blender 版本的视频编码器。
- **无声版优先**作为 H3 运动参考；带声版仅供审片，且必须显式忽略其声音。
- **不绑定旧盘符**：重建脚本用 `--output` 参数接收输出目录。
- 迁移电脑要复制 `.blend` 与资产，仅上传技能不带工程。
