# Crowd Scale Shorts · 离谱人数系列短片

用于创作“假如 XXXX 有 XXXX 人”类荒诞生活短视频的 Agent Skill。

它把熟悉场景中的人数放大，再从一个普通人的小目标出发，推导连续麻烦、世界规则和结尾反杀。支持参考片拆解、原创选题、系列角色、脚本及 AI 分镜，不是视频生成模型。

## 安装

将仓库完整下载或克隆到本机，再把仓库内容放进技能目录：

```text
~/.codex/skills/crowdScaleShorts/
  SKILL.md
  README.md
  references/
```

刷新 Agent 的技能发现。其他支持 SKILL.md 的 Agent 也可读取，但实际视频读取、转写、图像及视频生成能力由所在环境提供。

纯策划不需要 API Key、Bun 或 Blender。分析本地视频可安装 FFmpeg/ffprobe；没有转写工具时可用字幕和用户核准的对白，不应虚构听到的台词。

## 使用示例

```text
请使用 crowd-scale-shorts 技能，策划“假如某场所有十万人”系列。
我给你的参考片已经用过宿舍和班级题材，这两个不要再推荐。
先给我5个新选题，每个包含日常目标、三层递进和结尾反杀，
标出是否与参考包袱重复。本轮只策划，不生成视频。
```

```text
根据已选题材写一集60秒脚本，固定主角是普通打工人。
开场立刻让观众看懂人数规模，人物一本正经地处理离谱规则。
给出对白、动作、景别、声音和时间分配，不加入广告。
```

```text
拆解我给的参考视频，区分实际观察、近似时间和你的推断。
提取结构，但不要照搬原片台词、人物形象和具体笑点。
```

## 文件说明

- SKILL.md：触发条件、选题避重、因果升级、人物与输出检查。
- references/referenceAnalysis.md：参考片分析方法与本次样片经验。
- references/episodeTemplate.md：候选、系列设定和分镜表模板。
- references/productionWorkflow.md：AI 制作与规模画面的实现原则。

“宿舍十万人”的分析来自用户提供的约112秒样片；用户另行指出班级十万人题材也已存在，示例因此排除两者。这是当前案例的避重条件，不代表所有用户永久禁用校园题材。

仓库仅包含方法与模板，不包含参考视频、演员肖像、商品素材、账户凭证或用户项目。无法保证播放量或一次生成成功；实际作品仍需审看节奏、表演、连续性与原创差异。
