# 剧本规范

面向 AI 短剧：剧本既给人看，也给后面的分镜、配音、片段拆分当输入。凡是这几步要用到的信息，剧本阶段就要写清楚。

## 一、文件结构

```text
1.剧本/
├── 剧本.md          # 主文件，只写剧情
├── 时长表.md        # estimate_duration.py 输出
├── 台词台账.md      # 逐句可核
├── 资产清单.md      # 人物/场景/道具/后期界面
└── 片段切分表.md    # 给 H3 阶段
```

剧本.md 不写镜号、不写景别、不写提示词。混在一起，后面改一句台词要动三个文件。

## 二、剧本格式

```markdown
# 《剧名》

**类型：** 预付卡骗局 / 消费陷阱 / 套路揭秘
**人物：** 赵叔、老钱、阿强、王阿姨
**建议时长：** 88 秒

---

## 第一场｜3秒钩子

### 小区门口 日 外

△王阿姨举着两张卡，堵在赵叔面前。

**王阿姨：**
“老赵，你当初说这家店靠谱，我充了六万！”

**赵叔：**
“我卡里还有八万呢！”

△两人同时回头。卷帘门拉到底。

**画面定格。**

**字幕：三个月前。**

---
```

### 格式约定

| 元素 | 写法 | 说明 |
| --- | --- | --- |
| 场次 | `## 第X场｜功能` | 功能写“3秒钩子/入局/加码/收割/揭底/回环” |
| 场景行 | `### 地点 日/夜 内/外` | 与资产清单的场景名一致 |
| 人物行 | `**人物：** 赵叔、老钱` | 只在场次开头写一次 |
| 动作 | `△` 开头 | 只写看得见的动作和画面 |
| 台词 | `**角色：**` + 中文引号 | 一人一段，不混排 |
| 重音 | `**啪。**` 单独成行 | 用于盖章、落槌、关门等声音点 |
| 定格 | `**画面定格。**` | 只用在钩子和结尾 |
| 字幕 | `**字幕：X天前。**` | 回溯字幕只写时间，不写解释 |

### 不要写

- 镜号、景别、焦段、运镜——分镜阶段解决
- “他感到后悔”“气氛变得尴尬”——换成动作
- 旁白解释剧情——本系列不用旁白
- 括号里的表演指导——除非是配音情感标注，另存文件

## 三、时长预算

中文口播按 **4.5 字/秒** 估，快节奏可到 4.8，慢速独白 4.2。

| 项 | 预算 |
| --- | --- |
| 每句台词停顿 | 0.35 秒 |
| 每次递物/转身/起身 | 0.6–1.0 秒 |
| 每场转场 | 1 秒 |
| 成片目标 | 85–95 秒 |
| 台词总量 | 约 280–360 字 |

一个 90 秒的片子，真正在说话的时间只有 70 秒左右，剩下的给动作、停顿和定格。**台词写超了，不要加速语速，要删场次。**

## 四、七拍在剧本里的落点

| 拍 | 落在第几场 | 剧本检查点 |
| --- | --- | --- |
| 钩子 | 第 1 场 | 第一句 ≤15 字，带金额或动作 |
| 回溯 | 第 1 场末 | 只写“字幕：X天前”，不解释 |
| 入局 | 第 2 场 | 赵叔要有一段“算账”，3–5 句 |
| 加码 | 第 4 场 | 必须提一句“上次真给了”，做背书 |
| 收割 | 第 6 场 | 只写一个动作引爆：限额、关门、占线、拉黑 |
| 揭底 | 第 7 场 | 阿强问，老钱答，老钱不认罪 |
| 回环 | 第 8 场 | 同一地点、同一构图，人物状态相反 |

## 五、台词写法

### 长度

- 单句 ≤15 字，超过就拆
- 老钱单段 ≤60 字，超过观众记不住
- 赵叔算账段 3–5 句，多了像讲课

### 说话人绑定

一个镜头里只能有一张清楚的嘴。剧本阶段就要避免“两人同时开口”：

- 不写“两人异口同声”
- 不写“众人议论”
- 阿强问完，老钱再接，中间留一个反应动作

### 结尾留白

每场最后一句台词说完，留 0.8–1.5 秒给表情或动作。剧本里用 `△` 写出来：

```markdown
**赵叔：**
“我卡里还有八万呢！”

△赵叔低头看卡，没再说话。
```

## 六、片段切分规则

片段是给 H3 的生成单元，不是剧本场次。一场可以切两个片段，两场也可以合成一个片段。

| 规则 | 说明 |
| --- | --- |
| 一个片段一个叙事目的 | 写不出“这个片段让观众知道了什么”，就拆错了 |
| 2–3 个镜头 | 一个建立、一个推近、一个落到反应 |
| 8–15 秒 | 低于 6 秒信息不够，高于 16 秒模型容易崩 |
| 台词在前 85% 结束 | 最后 15% 留闭口反应，避免尾字被截 |
| 结尾留剪辑点 | 落卡、关门、递手机、抬头，都可以硬切 |
| 首帧已在动作中 | 不写“先站着，然后转身” |

### 片段切分表格式

| 片段 | 时长 | 场次 | 叙事目的 | 镜头数 | 结尾剪辑点 |
| --- | --- | --- | --- | --- | --- |
| 01 | 0–8s | 第一场 | 两个人的钱都没了 | 2 | 卷帘门定格 |
| 02 | 8–20s | 第二场 | 赵叔算清“等于五折” | 3 | 卡推到桌上 |
| 03 | 20–30s | 第三场 | 观众先懂现金流 | 2 | 老钱合上账本 |

## 七、台词台账格式

逐句记录，供配音和后期核对：

| 编号 | 场次 | 角色 | 台词 | 字数 | 预估秒 |
| --- | --- | --- | --- | --- | --- |
| D01 | 1 | 王阿姨 | 老赵，你当初说这家店靠谱，我充了六万！ | 20 | 4.4 |
| D02 | 1 | 赵叔 | 我卡里还有八万呢！ | 9 | 2.0 |

台账由 `scripts/estimate_duration.py --ledger 台词台账.md` 直接生成，不要手抄。

## 八、交稿自检

剧本：

- [ ] 第一场第一句 ≤15 字，带金额或动作
- [ ] 开场与结尾同一场景、同一构图
- [ ] 每场只做一件事，场次标题能看出功能
- [ ] 台词总量 280–360 字
- [ ] 单句 ≤15 字，老钱单段 ≤60 字
- [ ] 没有“两人同时开口”“众人议论”
- [ ] 每场人物的第一反应，符合他**此刻掌握的信息**（他不知道的事，不能演出来）
- [ ] 每场结束时，每个人物手上有什么、知道什么，都写下来核对过
- [ ] 全剧「事实表」逐条核对过：谁伤在哪、钱给谁、东西在谁手上、人站在哪儿
- [ ] 每句提出要求的台词，都符合说这话的人的利益方向
- [ ] 同一个漏洞若改了两遍还没好，停下来改场次顺序，不要继续改台词
- [ ] 每场结尾有可拍的动作或表情
- [ ] 定格只出现两次（开头、结尾）

时长：

- [ ] 跑过 `estimate_duration.py`，总时长 60–110 秒
- [ ] 每场预估秒数与骨架标注相差不超过 20%
- [ ] 台词在片段前 85% 结束

合规：

- [ ] 无真实品牌、平台、机构、地名
- [ ] 无操作路径演示（怎么办卡、怎么转账、怎么维权）
- [ ] 无“保本”“稳赚”等承诺性表述
- [ ] 片尾有虚构声明
- [ ] 医疗/金融题材有免责声明

## 九、常见返工原因

来自前几集的复盘，写剧本时就要避开：

1. **台词超量**：写到 120 秒，靠加速念完，观众听不清。解决：删场次，不是删字。
2. **说话人串线**：两人同框都张嘴，后期音色对不上。解决：剧本阶段就规定谁闭嘴。
3. **首帧静止**：片段开头像图片。解决：片段第一句动作写成“正在发生”。
4. **动作不符合现实**：已经卖成品了还在搬原料。解决：每个动作问一句“他此刻为什么做这件事”。
5. **结尾没有落点**：说完就黑屏。解决：每场最后写一个 `△` 动作。
6. **字幕说教**：写“提高警惕”。解决：第二行必须是动作，不是口号。
7. **反应不符合人物此刻的信息**：写赵叔正跟电话里的“女儿”说话，真女儿已经站到面前，他却只是藏袋子——他此刻应该先懵、先问“你怎么在这儿”，藏袋子是后面才轮得到的事。**作者的叙事需要，不能替代人物的认知顺序。**
   解决：落笔前给这场写一行「他此刻知道什么／不知道什么」，再写第一反应；反应只由信息决定。
   连带检查：**这个人物在场，后面的戏还成不成立**。如果不成立，不要急着“把他支走”——那只是补丁，观众会问“为什么偏偏这时候走”。正确的问法是：**这场戏到底该发生在事件的哪个时间点**（见第 9 条）。
8. **事实与处境不自洽**：这类错误读者一眼能看出，且一出现整集就假。高频三种：
   - **身体状况**：撞了人的角色在电话里喊“我疼”——她是加害方，身上没伤，她该怕的是对方家属和赔钱。
   - **利益方向反了**：骗子说“要现金，留记录”——他要现金恰恰是为了**不**留记录。凡是“某人提出某个要求”，先问一句这要求对他有利吗。
   - **指代串人**：阿强问“那他们怎么知道你家座机”，可座机是赵叔家的。代词的指代对象一乱，观众直接出戏。
   解决：每句台词念一遍，问三件事——**符合他此刻的处境吗？符合他的利益吗？代词指的是同一个人吗？**
   加一条流程动作：**写完全剧，把所有“角色陈述的事实”列成一张表**（谁伤在哪、钱给谁、东西在谁手上、人站在哪儿），逐条对一遍，比通读有效。
9. **用台词修结构**（最费时间的一种返工）：同一个漏洞改三遍还改不好，问题就不在台词，在场次。
   案例：钩子要求「真女儿就站在他面前」，后文又要求「他继续去送钱」——女儿一出现骗局就破了，这两件事不可能共存。改台词（藏袋子 → 加问句 → 把人支走）都是补丁，越补越假；唯一解法是**把钩子挪到钱已经交出去之后**，让「女儿出现」成为戳破的时刻，而不是需要绕过的障碍。
   判断方法：**列出这场戏结束时，每个人物手上有什么、知道什么**。只要某个人物的状态会让他不可能做出下一场的行为，就要改场次顺序，不是改台词。
   一句话记：**台词改不动的，改的是结构。**
