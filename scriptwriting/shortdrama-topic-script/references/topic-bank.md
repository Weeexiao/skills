# 选题池

> 每次做完提案，把候选同步到这里。下次选题先看这张表，避免重复研究和重复拍摄。
> 状态只有四种：`已用`（已拍成片）、`可用`（评估通过，待排期）、`暂缓`（有价值但撞车/成本高/敏感）、`淘汰`（否决）。

## 使用规则

1. 新增候选必须写清：**一句话骗法 / 赵叔为什么信 / 怎么被反将一军**。
2. `暂缓` 的条目要写原因和“解冻条件”，否则半年后没人记得为什么搁置。
3. 拍完一集，把状态改成 `已用`，同时更新 `series-canon.md` 的机制台账。
4. 同一机制最多两集，且第二集必须换人物关系，不能只换行业。
