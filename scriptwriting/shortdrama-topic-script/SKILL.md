# 系列短剧：从选题到开拍脚本

给一个已经跑起来的系列短剧开发下一集，分两段交付：**先定拍什么，再写到能配音**。目标不是“找一个骗局”，而是找一个能塞进现有模具、机制没重复、成本拍得起，并且能在 90 秒内讲完的骗局。

## 何时使用

| 用户说 | 走哪一段 |
| --- | --- |
| “选个新一集题材”“下一集拍什么”“这个骗局能不能拍” | 阶段 A：选题（第 0–5 步） |
| “把选题写成剧本”“出一版台词”“扩成完整剧本” | 阶段 B：剧本（第 6–9 步） |
| 已有一版剧本，要控时长、查台词 | 直接跑 `scripts/estimate_duration.py`，再按第 8 步修 |

不适用：写 H3 提示词、拆镜头、生成故事板。交给 `ai-short-film-pipeline` 与 `h3-prompt-writing`。

## 三条铁律

1. **先读系列，再想题材。** 没有系列档案就先建一份（见 `references/series-canon.md`）。不读前作就提选题，十有八九撞机制。
2. **只换壳不算新选题。** 换了门店招牌、换了产品名字，但骗法还是“免费引流→恐吓→高价”，就是同一集。机制必须换。
3. **成本先于创意。** 新增场景 ≤2、新增角色 ≤1。超了就不是选题问题，是预算问题。

# 阶段 A：选题

## 第 0 步：读系列

1. 读 `references/series-canon.md`，取人物、场景、七拍结构、已用机制台账。
2. 项目在本地时，扫一遍已有的剧集目录，确认档案没落后于实际。重点看每集的**类型**和**核心机制**，不是标题。
3. 用户换了系列（不是赵叔）时，先按同一份档案模板重建，不要套用赵叔的人物关系。

## 第 1 步：机制盘点

把已用机制列成一张表：`集数 | 题材 | 核心机制 | 已经用掉的钩子`。

判断撞车的标准是**机制**，不是行业：

- 换行业不算新：保健品店 → 养生馆，还是“免费引流 + 健康恐吓”。
- 换标的物不算新：字画 → 老物件，还是“高估价 + 先收费 + 不成交”。
- 换入口不算新：线下课 → 直播间，还是“会销逼单”。

## 第 2 步：生成候选

四个来源，按顺序取，不要一上来就头脑风暴：

1. **机制空白**：台账里没出现过的资金/信任结构。常见空白：预付资金池、身份伪造、平台垫资、服务型会员、押金池、代运营。
2. **时效热点**：近 6 个月官方提示、媒体调查、平台治理通告。用搜索核实，不要凭印象。
3. **观众日常**：小区门口、菜市场、家长群、老年大学、体检中心。越日常越有代入感。
4. **人物关系**：现有角色还能不能产生新关系？例如让赵叔从受害者变成“拉人头的人”，比换十个骗局都新。

每个候选先写三行：**一句话骗法 / 赵叔为什么信 / 最后怎么被反将一军**。三行写不出来就淘汰。

## 第 3 步：打分

按五维加权，权重固定为：钩子 25%、差异化 20%、可执行 20%、时效 20%、情感 15%。

用 `scripts/score_topics.py` 算，不要手算，避免前后不一致：

```bash
python scripts/score_topics.py candidates.json
```

打分锚点、案例与权重调整规则见 `references/topic-scorecard.md`。

**一票否决项**（出现任意一条直接出局，不参与排名）：

- 核心机制与已有剧集重合
- 新增场景 >2 或新增角色 >1
- 没有“反将一军”的收尾，只能靠字幕说教
- 必须依赖特效/屏中屏/换脸才能成立
- 需要演示具体操作路径才讲得清

## 第 4 步：把第一名做成可开写的方案

用 `references/episode-outline-template.md` 填，八节一个都不能少：

1. 一句话卖点
2. 备选标题（含一个提问式）
3. 三秒钩子（必须是一段能直接拍的对话，不是描述）
4. 8 场骨架（场次/时长/场景/事件/信息变化）
5. 三句必须写对的台词
6. 两行结尾字幕
7. 新增资产清单
8. 合规注意

第二名、第三名只写“钩子 + 骨架 + 评估”，篇幅不超过第一名的一半。

## 第 5 步：落盘

- 提案写到 `0.选题库/`，文件名带日期：`<系列名>-新一集选题提案-YYYYMMDD.md`
- 已评估的候选同步进 `references/topic-bank.md`，标注 `可用 / 暂缓 / 已用`，下次不重复研究
- 用户确认选题后，按项目下一个编号建 `<编号>.<剧名>/`，进入阶段 B
- 不要在建目录前就写剧本

# 阶段 B：剧本

输入是第 4 步的八场骨架。输出是一份能直接配音、能直接拆片段的剧本，不是文学稿。

## 第 6 步：把骨架扩成场次

按 `references/script-standard.md` 的格式写，用 `assets/剧本模板.md` 起头。

每个场次只做一件事，场次标题写清功能：

```markdown
## 第一场｜3秒钩子
### 保健品店门口 日 外

△赵叔抱着两大箱保健品，气冲冲地堵在店门口。

**赵叔：**
“我就来领了六个鸡蛋！”

**赵叔：**
“怎么最后花了三万二？”

画面定格。

**字幕：三天前。**
```

硬规则：

- 动作行一律以 `△` 开头，只写看得见的东西
- 台词单独成段，用中文引号，一人一段，不混排
- 角色名统一用 `**赵叔：**` 格式，方便脚本统计
- 不写镜号、不写景别、不写“特写”——那是分镜阶段的事
- 每场结尾留一个可剪辑的动作或表情

## 第 7 步：写台词

**赵叔**：短句，爱算账，爱举例。一场最多两次“算账”，第三次就腻。

- “一万送一万？那不白给吗？”
- “我天天在这儿买，能跑哪去？”

**老钱**：不承认骗，只讲成本、记账、周转。每集只给他两段长台词，第 3 场和第 7 场。

- “我收他一万，账上就多一万。送他的一万，是记在账上的。”

**阿强**：替观众问那句傻问题，问完必须有一个“愣住”的反应。

**第二受害者（王阿姨/小雅）**：只在第 1 场和第 8 场出现，最后一句必须具体到一笔钱的用途。

台词写完先自己念一遍：**超过 15 字的句子，能砍就砍**。

## 第 8 步：控时长

不要凭感觉估时长，跑脚本：

```bash
python scripts/estimate_duration.py 剧本.md
python scripts/estimate_duration.py 剧本.md --rate 4.5 --out 时长表.md
```

输出每场的台词条数、字数、预估秒数与累计秒数，并按说话人汇总。默认 4.5 字/秒、每句 0.35 秒停顿、每场 1 秒转场。

判断标准：

| 总时长 | 处理 |
| --- | --- |
| < 60 秒 | 加一场“加码”或一次“甜头兑现”，不要拉长单句 |
| 60–80 秒 | 可发，适合快节奏平台 |
| 80–100 秒 | 本系列的目标区间 |
| > 110 秒 | 先删重复解释，再合并场次，最后才考虑删台词 |

改完必须重跑，不要手改数字。

## 第 9 步：切片段与交稿

按 `references/script-standard.md` 的片段规则切：

- 一个片段只承担一个叙事目的
- 2–3 个镜头，8–15 秒
- 每片段结尾留自然剪辑点
- 台词在该片段前 85% 结束
- 8 场通常切成 8–9 个片段

交稿清单：

1. `1.剧本/剧本.md` — 带场次、动作、台词、定格字幕
2. `1.剧本/时长表.md` — 脚本输出
3. `1.剧本/台词台账.md` — 场次/角色/原文/字数/预估秒，逐句可核
4. `1.剧本/资产清单.md` — 人物复用表 + 新增场景/道具/后期界面
5. `1.剧本/片段切分表.md` — 片段号/时长/叙事目的/镜头数/结尾剪辑点

交 `ai-short-film-pipeline` 前，逐条过 `references/script-standard.md` 末尾的自检清单。

## 合规红线

- 只揭机制，不教操作路径；不演示如何办卡、如何转账、如何维权
- 不出现真实品牌、平台、机构、地名，统一虚构名
- 金融类不写具体收益率承诺，不写“保本”“稳赚”
- 片尾固定一行：剧情为虚构创作，人物与机构均为化名
- 医疗、金融题材加免责声明；不做绝对化断言
