# POV 分镜设计

写分镜时读取。默认严格眼睛视点；爽文、灾难、人生体验共用物理视点约束，各自的情绪曲线分别设计。

## 一、主角是视点，不是画内演员

| 常见误写 | 严格POV改法 |
|---|---|
| 跟着主角背影逃跑 | 视点自己沿通路移动，近墙向后掠过，只有独立路人从旁边经过 |
| 用自己的肩影交代空间 | 用门框、桌沿、他人的手与既定位置交代，自己的肩不入画 |
| 拍主角跌倒/被拉进屋 | 主观视野失衡下降/被拉向门洞，不切到外部拍两人 |
| 所有人一直看镜头 | 交互者看向“你”；逃难者看危险或出口，拍照者看手机屏幕 |
| 把主角头像换成看不清的影子 | 仍属主角身体外部视图；默认不用背影、自己的影子和镜像 |

问每镜“眼睛在哪、朝哪、为什么动、停在哪”。答不清就先改动作和空间，不堆摄影术语。无正脸不等于严格第一人称。

## 二、主观镜与身体局部

- **A主观镜**：画内没有视点主人，靠他人、环境、声音推进。
- **B身体局部镜**：自己的手/短前臂从下缘伸入；按需要低头看脚，手腕/脚与视点身体的位置合理。
- **C抽离镜**：拍到主角背影等外部视图，默认0。仅用户明确要求混合视角时例外，标明这一镜离开严格POV。

不机械凑80/15比例，不为凑“替身”加影子或肩膀。别把独立路人的背影误记成主角抽离镜。

## 三、视线与身体驱动运动

| 动作 | 可执行描述 | 常见失败 |
|---|---|---|
| 看向巨响 | 短促转向，允许轻微过冲，立即落稳于声源 | 匀速慢摇好几秒 |
| 走/跑 | 眼位随几次脚步短促起伏，墙面从两侧向后流动 | 漂浮滑轨，或镜头一直跟在同一背影后 |
| 躲避落石 | 视点下沉贴墙，短段手掌从下缘触墙，视线重新落到出口 | 外拍主角蹲下，或整段随机摇晃 |
| 被抓腕 | 明确自己的哪只腕、邻居哪只手，眼位穿过门洞 |手臂换人、穿墙、拍到两人合照 |
| 倒地 | 眼位下降、俯仰/轻滚后停在低位向上看 | 空中绕着倒地演员拍 |
| 固定展陈 | 镜头不动，游客俯身进入视野 | 为“拟人”仍加呼吸抖动，或镜头看到自己的遗骸 |

运动速度按情境调，不能把一次成功的秒数写成所有片段固定参数。快运动短暂模糊、落稳后恢复清晰，别用持续柔焦遮掉瑕疵。

微推/后退必须有身体前倾、脚步或外力来源；注意力变化也可用视线/对焦表达。不要把悬浮拉远、滑动变焦当真实人眼动作。用户要风格化效果时再说明并采用。

## 四、关键动作和他人反应

每个主动作保留起势、接触或完成点、结果。用户要拍照，就显示手机及镜头朝向、取景、拍摄触发和放下；“想拍但放弃”改变了需求。

持物手要接到正确人的袖口。抓腕要明确动作方向与接触部位，自己的手只从合理的下缘出现。不要靠音效或旁白宣布画面里没发生的动作。

人群分近、中、远层，至少几种可辨识反应，且视点路线可通过。惊慌可以护头、缩身、改道、丢下物品、拉住同伴；不必每个人直视镜头或同步惊叫。人数本身不能替代表演。

逆袭爽文才使用对手“轻蔑—惊愕—仰望”；历史逃生不凭空添加羞辱或崇拜。

## 五、空间、组接和转场

先建简短空间账本：眼位、朝向、通路、门的铰链/把手/开合、固定道具、人物左右与光源。画面左右随转头改变，世界位置不随参考图任意翻转。

同场图逐格比对门、窗、台阶、陶罐等锚点；进入室内前后明确是否已过门槛。同一角色用实际采用外观，不换回另一张早期人设。

相邻镜至少有一条明确连接：动作、空间、视线落点、信息因果、声音或情绪。支持合理时间跳转，不能为了流畅假装灾害进程从未跳时。连续眼位转向不机械套“每镜至少30度”；不通过绕到主角身后解释空间。

常用转场是视线匹配、动作接续、遮挡、声音桥、明确时间跳转后的构图匹配。黑场/眨眼只是可选手法，若生成出眼睑黑带或分屏，应简化为清楚硬切，不为保留特效继续付费试错。

## 六、画面构成

- **主角在场感**：短段手部触感、脚步、呼吸、他人对“你”的视线或动作；按故事选，不强制凑满两种。
- **前景遮挡**：门框、桌边、独立路人的手臂可经过；不能用自己的肩膀作为过肩镜替代品。
- **视线引导**：街道、走廊、门洞给出可通过路线。勿让某个居中同速路人变成默认主角。
- **景深与清晰度**：焦点有动机，保留辨识环境和关键动作所需细节；不宣称浅景深就等于真实人眼。
- **光线**：符合空间中的日光、窗、灯、火把等可解释来源，不要求每个光源都必须出现在画内。

## 七、与参考图配合

简单连续动作优先单幅；多步变化可用四宫格，必须按时间顺序扩展为全屏。两者都要检查空间和身体归属。拼图、横框、镜面、黑带或互相冲突的参考可能干扰构图，出现重复/分隔时先查实际输入。详细生产与恢复见 [productionWorkflow.md](productionWorkflow.md)。

## 八、镜头行写法

推荐“看的方式—视线主体—具体动作”，正文格式服从用户或应用需要。例如：

> △ 主观贴墙下沉——短段手掌从画面下缘撑住粗石；左侧屋檐传来断裂声，视线短促转向后停稳，远处几名市民护头绕开落石。

这是一条主观动作，不是拍一个人在墙边蹲下。不要把多个完整机位变化压进一句话而没有时间完成。

## 九、交付前检查

- 是否把“零正脸”误当成严格POV，仍有后脑、肩膀、背影或自己的倒影？
- 运动是否由身体/注意力/外力触发，是否落到清楚目标？
- 关键动作是否有可辨识完成点，而非只有持物姿态？
- 群众是否有情绪、层次和通路，且注意方向合理？
- 前后门、手、角色、道具是否连续？有无悬浮、穿墙或换手？
- 是否一幅完整画面，有无上下复制、两宫格、边框或黑带？
- 检查证据是提示词、抽帧、完整播放还是听验？如实注明，不能互相替代。
