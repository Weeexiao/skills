# POV 分镜设计体系

写剧本前必读。本文件把通用电影分镜（镜头语言目录、镜头组接判断）**反转成第一人称版本**——常规分镜的很多铁律在 POV 里必须倒过来用。

---

## 零、先记住这个反转：五条常规规则在 POV 里全部作废

| 常规分镜（第三人称） | POV 分镜（第一人称） |
|---|---|
| 人物**不要**看镜头 | 对象**必须**直视镜头——镜头就是"我"的眼睛 |
| 有正反打：A 看 B，切 B 看 A | **只有单向**——任何人都看镜头，镜头永远不回看 |
| 用过肩镜交代对话关系 | **禁用过肩镜**（会带出"我"的肩膀），改用前景虚影/遮挡 |
| 摄影机在外部，可自由走位 | 摄影机**就是**主角，走位=视线转移，轴线固定不动 |
| 主角有正脸、有表演 | 主角**绝不入画正面**，情绪由他人反应+声音承担 |

**判断准则**：写完一行 `△`，问自己——"这行的摄影机挂在哪里？朝哪？在做什么运动？"答不上来，就不是分镜，是小说。

## 一、三类镜头（POV 专属分类，全片配比固定）

| 类型 | 定义 | 占比 | 用途 |
|---|---|---|---|
| **A · 主观镜** | 主角眼睛所见，画内没有主角任何部位 | **约 80%** | 叙事主体。看人、看物、看环境 |
| **B · 身体镜** | 第一视角但视线下移，画内有主角的手/脚/局部 | **约 15%** | 动作与仪式：握手、签字、举拳、握奖杯、踩上台阶 |
| **C · 抽离镜** | 从背后或侧后方拍主角的**背影**（绝不给正脸） | **≤ 2 次** | 只用在集群高潮的开场或最后定格 |

**C 类使用铁律**：全场最多 1-2 次。第一人称突然"灵魂出窍"会让观众出戏，用多了片子就散了。背影必须背对镜头、脸完全不可见。

---

## 二、视线驱动的运镜（POV 没有"无动机运镜"）

POV 里摄影机的每一次运动**都是主角注意力的变化**，所以运镜必须带着心理动机：

| 运镜 | POV 语义 | 典型用法（对应幕次） |
|---|---|---|
| 抬视线（Tilt Up） | 从低处仰望 → 敬畏、被压制、看到高位者 | 幕一（仰视羞辱者）、幕五（仰望加冕） |
| 压视线（Tilt Down） | 从高处俯瞰 → 掌控、怜悯、君临 | 幕四（俯瞰跪拜人海） |
| 视线摇（Pan） | 扫视 → 清点人数、寻找某张脸 | 幕四（扫过一排排人脸） |
| 视线定（Hold） | 注意力锁死 → 震惊、不愿相信 | 幕二（盯住异常之物）、幕三（盯住揭晓信息） |
| 微推（Push In） | 注意力收紧 → 逼近真相 | 幕二伏笔、幕三反转 |
| 后拉（Pull Back） | 抽离 → 揭示规模（"原来这么多人"） | 幕四开头，从一张脸拉出满场 |
| 急甩（Whip Pan） | 猝然回头 → 被打断、被惊到 | 幕一（有人从背后喊"你"） |
| 轻微手持晃 | 呼吸不稳 → 紧张、委屈、疼痛 | 幕一被羞辱时 |
| **骤稳** | **从晃到稳 → 掌控感回归** | **幕三反转瞬间（POV 独有语法：稳=强）** |
| 滑动变焦（Dolly Zoom） | 认知崩塌 → 世界观被推翻 | 幕三身份揭晓的那一帧 |
| 视线下压＋手入画 | 视线落到自己手上 → 决心 | 幕二结尾（决定的那一刻） |

**关键提示**：`骤稳` 是 POV 独有的强力语法。前半段镜头一直带轻微晃动（真实人眼），反转那一刻镜头**突然变得纹丝不动**——观众会本能地感到"这个人变了"。

## 三、五幕 × 分镜设计策略

| 幕 | 分镜设计策略 | 主导手法 |
|---|---|---|
| 一 · 被轻视 | 视线压低（被俯视）；**前景遮挡**（别人的腿、手臂、衣袖从镜头前划过）；轻微手持晃；对象占据画面上方，留大片天花板/天空 | 主观微仰 + 前景遮挡 + 手持晃 |
| 二 · 伏笔 | **视线定住一拍**；焦点从模糊到清晰（Rack Focus）；画面内只有一个小物件亮起 | 视线定 + 焦点转换 + 微推 |
| 三 · 反转 | **急甩 → 骤稳**；滑动变焦；环境音骤降为死寂；对象的表情在镜头里逐帧崩掉 | 骤稳 + 变焦 + 视线落点 |
| 四 · 集体崇拜 | **后拉揭示规模**；视线摇过满场仰望的脸；前景的手从画面下方伸上来（求握手）；一记背影抽离镜 | 后拉 + 摇 + 身体镜 + 1 次背影 |
| 五 · 高光定格 | 视线抬起；手中物的**大特写**（奖杯/钟锤/圣旨/金牌）；上最后一格台阶的脚；定格 | 身体镜 + 大特写 + 定格 |

## 四、主角"不在场"的五种替身

主角不能入画，但观众必须时刻感到"我"在场。用这五样东西代替主角的身体：

1. **手**——最常用。握杯、握手、签字、按快门、握拳、握住奖杯/钟锤/剑柄。手是"我"的情绪出口：发抖=恐惧，收紧=决心。
2. **脚 / 鞋**——走过红毯的鞋、踩上领奖台的脚、退后一步的鞋。用于"我"的移动与身份变化（磨破的旧皮鞋 → 锃亮的新皮鞋）。
3. **影子**——被灯光拉长的影子，尤其在被羞辱的时刻（孤独、渺小）。也可用于反转后（影子笼罩住对方）。
4. **他人的视线与称呼**——别人盯着镜头喊"你"，观众立刻知道"我"站在那儿。**这是最高效的一种**。
5. **画外的呼吸/喘息**——音轨上属于"我"的声音。委屈时的抽气、胜利时的长吐气。

## 五、POV 取景与构图法则

- **主观框偏移**：把主体放在画面中偏左或偏右，而不是正中——模拟人眼注意力的自然偏移。正中构图只留给"仪式性瞬间"（加冕、定格）。
- **被俯视构图**：俯视我的人占据画面上方 1/3，镜头下方留出大片空地/天花板/天空 → 渺小感。
- **俯瞰构图**：对象密集铺满画面**下半部**，镜头居高临下 → 君临感。上下翻转构图 = 地位翻转。
- **前景遮挡**：门框、肩膀、酒杯、车窗从镜头前划过 → 增强"我在场"的实感，同时制造窥视感。
- **视线引导线**：走廊、台阶、红毯、通道向画面前方延伸 → 我在向前走。
- **遮挡揭示**（POV 最强揭示手法）：前景的人/物让开 → 露出关键物（奖杯、圣旨、钟、榜单）。比任何推镜都有效。
- **不做过肩镜**：需要空间关系时，用"前景肩部虚影"一格代替（画面下缘一抹虚掉的肩膀）。

## 六、他人视线三连（全片弧线藏在眼睛里）

同一张脸，三种眼神，就是全片的弧线。写剧本时**至少给对手角色设计三次看镜头的眼神**：

1. **幕一·轻蔑的眼**——斜眼、嗤笑、上下打量镜头。
2. **幕三·惊愕的眼**——瞳孔一缩，笑意从嘴角消失，视线开始躲。
3. **幕四·仰望的眼**——抬头，眼眶发红，或跪着仰视镜头。

这三眼的写法示例：
```
执事弟子（轻蔑，嗤笑）：灵根都废了，还扫什么山门？
```
→ 同一角色，幕四：
```
执事弟子（震惊，失声）：不可能……是你？
```

## 七、镜头组接（POV 版）

写逐镜前先过一遍这五步（方法来自通用镜头组接，此处已按 POV 改写）：

1. **段落任务**——这一场只推进什么信息/情绪。
2. **观看顺序**——观众先看到什么，再理解什么，最后得到什么。
3. **景别分工**——要空间关系给远景/全景；要行动给中景；要触感/选择/情绪给特写。**不要机械"远中近"轮流排**。
4. **动作链**——关键动作保留起势、关键点、结果；次要过程只留变化节点。
5. **相邻连接**——相邻两条 `△` 之间至少有下面一种真实连接：

| 连接类型 | 在 POV 里怎么写 |
|---|---|
| 信息/因果 | 上一镜提出问题（"这是什么？"），下一镜给答案 |
| 动作/动势 | 在动作峰值切：抬手 → 下一镜手已握住奖杯 |
| 空间 | 先给全景建立位置，再进局部特写 |
| 视觉 | 形状/颜色/位置相似才做匹配（如圆形钟盘 → 圆形奖牌） |
| 声音 | 下一场的声音**先进来**（掌声、钟声、欢呼），画面后到 |
| 情绪 | 用他人的反应镜承接前后情绪 |

**切点位置**（按优先级）：动作完成点 ＞ 视线落点 ＞ 信息揭示点 ＞ 说话权转移 ＞ 情绪变化点。

## 八、转场六式（POV 专属）与两个禁忌

**可用**：
1. **动作匹配**——抬手 → 下一场抬手
2. **视线匹配**——看向某物 → 下一场该物在视野中
3. **遮挡转场**——门框/人墙/黑影完全遮住画面后切入
4. **焦点转场**——虚焦 → 实焦（世界向"我"聚焦）
5. **声音桥（J-cut/L-cut）**——下一场的掌声/钟声先进来
6. **闭眼/睁眼**——黑场 → 天亮（POV 最自然的时空跳跃）

**禁忌**：
- ❌ **越轴**——POV 有一根固定轴线：摄影机（我）在轴一端，对象在另一端。全场不得"绕到对面去拍"。需要表现移动时，用场景锚点（门、台阶、走廊）而不是空间翻转。
- ❌ **无动机跳切**——POV 的"我"必须是连续的一个人，突然跳切会让观众失去身体感。

其它连续性要求：同场景锁定门窗、家具、道具、时段、光源方向；相邻镜机位差 ≥30°（或明显改变景别/焦段）以避免跳切；景别跳跃通常不超过三级。

## 九、光线与质感锚点

- **每个光源都必须绑定画内实体**：窗、台灯、火把、屏幕、聚光灯、闪光灯连闪。POV 的光是"我眼睛看到的光"，不能是无来源的氛围光。
- **以浅景深为主**（人眼感）；焦点是 POV 的重要叙事工具（谁清楚 = 我在关注谁）。
- **闪光灯连成一片**是"集体崇拜"幕的标准光效；**死寂中的一束顶光**是"加冕"幕的标准光效。
- 摄影锚点（选一句写进提示词）：`ARRI Alexa LF 浅景深` / `Sony VENICE 2 高宽容度` / `35mm 胶片颗粒` / `90 年代 DV 怀旧质感`（按题材基调选）。
- 真人质感：保留毛孔、细纹、次表面透光；不要写成广告模特式的正面念词。

## 十、`△` 行写法：从"描述"升级为"分镜"

`△` 行就是分镜。**每条 `△` 必须回答"镜头在哪、朝哪、怎么动、看到什么"。**

**四要素公式**：`{看的方式}——{看到什么}{正在发生什么}`

| 反例（小说句，无镜头） | 正例（POV 分镜） |
|---|---|
| `△ 阿桃走过铁轨。` | `△ 主观下摇，随脚步轻晃——一双草鞋踩过积水的石阶。` |
| `△ 巨魔的指节停在阴影边缘。` | `△ 视线定住，镜头屏息不动——阴影边缘，巨魔的指节一寸寸收住。` |
| `△ 他拿了奖杯。` | `△ 手部大特写——我的手握住冰冷的杯身，指节因为用力而发白。` |
| `△ 全场鼓掌。` | `△ 镜头猛然后拉——从一张脸拉出满场起立的人海，掌声轰然盖过一切。` |
| `△ 主角很生气。` | `△ 镜头微微一沉，呼吸声变粗——前方的脸在视野里晃了一下。` |
| `△ 主角转身离开。` | `△ 视线下压到地面，镜头开始向前移动——地面一块块向身后退去。` |

**镜型词表**（写在 `△` 句首，一望即知）：

- 主观 / 主观微仰 / 主观俯瞰 / 主观侧偏
- 手部特写 / 手部大特写 / 脚部特写 / 前景肩影
- 视线摇 / 视线定 / 视线急甩 / 视线抬起 / 视线下压
- 镜头微推 / 镜头后拉 / 镜头骤稳 / 滑动变焦
- 手持微晃 / 固定 / 定格
- 背影（仅 C 类，全片 ≤2 次）

**反面清单**（出现即改）：
- ❌ 出现"我"的脸、表情、正脸、全身
- ❌ 出现"过肩镜头"
- ❌ 无来源的光（"柔和的光洒下"）
- ❌ 空镜凑数（与本场信息/情绪无关的风景）
- ❌ 主观镜里"我"回头看自己（物理上不可能）

## 十一、交付前的分镜自检

1. A/B/C 三类镜配比是否约为 80/15/≤2？
2. 每条 `△` 都能答出"镜头在哪、朝哪、怎么动"？
3. 五幕的运镜策略是否到位？**反转那一镜有没有"骤稳"？**
4. 对手的三次"看镜头的眼神"是否都设计了？
5. 相邻 `△` 之间是否六类连接至少占一项？切点是否落在动作完成点或视线落点上？
6. 有没有出现主角正脸、过肩镜、越轴、无来源光？
7. 全片是否用到了至少两种"主角替身"（手/脚/影子/他人视线/画外呼吸）？
