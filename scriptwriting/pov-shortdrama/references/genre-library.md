# 「成功人生」题材卡库

写剧本前先在此定位题材；命中则直接取用角色卡、术语库、高光设定作为问答默认值与创作素材。未命中则用文末「题材卡模板」现场推导。

## 一、完整题材卡（8 类高频）

### 1. 修仙 / 仙侠
- **触发词**：修仙、仙侠、修真、道尊、飞升、宗门、渡劫
- **世界观/基调**：灵气大陆或古典仙门。等级森严，强者为尊，弱者连站的位置都没有。
- **默认高光时刻**：渡劫飞升那一刻——天劫雷云散开，三界修士跪伏山门，齐唤「道尊」。
- **角色卡**：
  - 我（第一视角）：被贬为杂役的外门弟子 / 被废了灵根的弃徒
  - 崇拜者：大长老、昔日同门、山下凡人
  - 对手：掌门之子 / 抢了「我」机缘的天骄
- **术语与道具库**：外门杂役、灵根、金丹、元婴、渡劫、天雷、宗门大比、藏经阁、本命飞剑、储物袋、灵石、拜师礼、山门石阶三千级
- **推荐场景**：宗门演武台、藏经阁顶层、九重天雷之下、山门长阶、祖师殿
- **经典金句**：`旁白（内心，平静）：当年赶我下山的人，今天跪在阶下。`
- **POV 细节钩子**：手——空无一物的掌心聚起雷光；视线——仰视演武台上俯视我的长老，反转后俯瞰满山跪拜的人头。

### 2. 足球（世界杯）
- **触发词**：足球、世界杯、国脚、前锋、大力神杯、点球
- **世界观/基调**：世界杯决赛夜。前 80 分钟被按在地上打，补时阶段绝杀。
- **默认高光时刻**：补时第 92 分钟凌空抽射绝杀，终场哨响，全队扛起「我」绕场，最后举起大力神杯。
- **角色卡**：
  - 我：被弃用的替补 / 被质疑「打不了硬仗」的 10 号
  - 崇拜者：老队长、全场十万球迷、看台上的父亲
  - 对手：对方核心球员 / 曾公开贬低「我」的评论员
- **术语与道具库**：补时、禁区弧顶、凌空抽射、世界波、帽子戏法、点球大战、越位、任意球、黄牌、帅位、更衣室、球迷看台、国旗披身、大力神杯
- **推荐场景**：球员通道、禁区弧顶、球门网后、更衣室、领奖台、漫天彩带
- **经典金句**：`旁白（内心，嘶哑）：他们说我这辈子进不了那个球——球进了。`
- **POV 细节钩子**：脚——球鞋踩上草皮、摆腿的那一瞬；视线——从球门死角抬起，扫过起立的人浪。

### 3. 创业 / 商战
- **触发词**：创业、老板、上市、敲钟、融资、被裁、首富
- **世界观/基调**：现代都市商战。起点极低——被裁、被拒、被亲戚看不起。
- **默认高光时刻**：交易所敲钟，全场起立，前老板挤到最前来握手。
- **角色卡**：
  - 我：被裁的打工人 / 被拒 20 次融资的创业者
  - 崇拜者：投资人、员工、媒体、同行
  - 对手：开除我的前老板 / 羞辱过我的投资人
- **术语与道具库**：期权、BP、A 轮、估值、破发、敲钟、市值、路演、对赌、独角兽、上市首日、创始人、董事会
- **推荐场景**：写字楼旋转门、出租屋书桌、路演厅、交易所走廊、敲钟台、庆功酒会
- **经典金句**：`旁白（内心，平静）：三年前那句「你不行」——今天，我替它敲了钟。`
- **POV 细节钩子**：手——敲钟、签对赌协议、握住曾经拒绝我的手；鞋——从磨破的旧皮鞋到走上红毯。

### 4. 电竞
- **触发词**：电竞、网游、职业选手、世界赛、夺冠、网吧
- **世界观/基调**：全球总决赛决赛夜。从网吧少年到世界之巅，全场高呼你的 ID。
- **默认高光时刻**：决胜局最后的团战五杀，水晶爆炸，全场从座位上跳起来高呼「我」的 ID。
- **角色卡**：
  - 我：被下放青训 / 被战队挂牌的选手
  - 崇拜者：队友、教练、解说、全场观众
  - 对手：曾隔网嘲讽「你菜」的明星选手
- **术语与道具库**：决胜局、五杀、超神、极限操作、水晶、团灭、解说、青训、挂牌、ID、冠军皮肤、召唤师峡谷、金雨
- **推荐场景**：选手通道、比赛席、大屏幕下、领奖台、漫天金雨
- **经典金句**：`旁白（内心，颤抖）：全场都在喊一个 ID——那是我的。`
- **POV 细节钩子**：手——鼠标/键盘最后一次点击、举起奖杯；视线——仰看大屏上的比分，转为俯瞰起立的观众席。

### 5. 都市隐藏大佬（战神 / 神医 / 首富）
- **触发词**：隐藏身份、大佬、战神、神医、赘婿、首富、装穷
- **世界观/基调**：现代都市，主角刻意低调，被岳家/亲戚/同学轮番轻贱。
- **默认高光时刻**：身份揭晓——顶级人物亲自前来行礼，全场震住，昔日轻贱「我」的人当众失态。
- **角色卡**：
  - 我：被全家看不起的赘婿 / 一个电话能调动全局的大人物
  - 崇拜者：将军、院长、董事长、市长
  - 对手：岳母、势利亲戚、看不起人的同学
- **术语与道具库**：一块表、一个电话、一枚徽章、商会、国医圣手、战区、军礼、聘礼、家宴、主桌、敬酒
- **推荐场景**：家族宴会厅、同学会、医院走廊、会所门口、寿宴主桌
- **经典金句**：`旁白（内心，淡然）：他们以为我在吃软饭——只是我懒得解释。`
- **POV 细节钩子**：手——不动声色地放下茶杯、接起那通电话；视线——扫过一张张从讥笑到僵住的脸。

### 6. 娱乐圈（影帝 / 歌王）
- **触发词**：娱乐圈、演员、影帝、歌手、颁奖礼、顶流、十八线
- **世界观/基调**：娱乐圈。从被抢角色、被嘲「过气」的十八线，到全场起立鼓掌。
- **默认高光时刻**：颁奖礼念出「我」的名字，全场起立，掌声雷动，「我」上台接过奖杯。
- **角色卡**：
  - 我：被雪藏的十八线 / 被换角的演员
  - 崇拜者：影后、导演、全场同行、粉丝
  - 对手：抢了「我」角色的一线 / 嘲讽「我」过气的营销号
- **术语与道具库**：影帝、视后、票房、番位、雪藏、试镜、杀青、红毯、颁奖礼、银幕、金像奖、评分、热搜、剧组
- **推荐场景**：试镜间、剧组片场、颁奖礼红毯、典礼主场、领奖台
- **经典金句**：`旁白（内心，哽咽）：话筒递到我手里时，全场都站了起来。`
- **POV 细节钩子**：手——接过奖杯、握话筒；视线——从黑压压的观众席抬起，定格在起立的人群。

### 7. 高考 / 学术
- **触发词**：高考、状元、学霸、学渣、科研、论文、诺奖、天才
- **世界观/基调**：校园或学术圈。被老师放弃、被同学嘲笑、被学界质疑。
- **默认高光时刻**：考场放榜 / 顶刊封面 / 国际颁奖——全场瞩目，「我」的名字被念出。
- **角色卡**：
  - 我：被贴「没救」标签的学渣 / 被撤稿质疑的研究者
  - 崇拜者：校长、教授、同学、全球同行
  - 对手：看不起「我」的班主任 / 否定「我」课题的评审
- **术语与道具库**：状元、放榜、清华北大、奥赛、顶刊、Nature、封面、答辩、诺奖、专利、实验室、录取通知书
- **推荐场景**：教室最后一排、放榜墙、答辩厅、实验室、国际会场、领奖台
- **经典金句**：`旁白（内心，平静）：那张卷子，我答完了——全国第一。`
- **POV 细节钩子**：手——笔尖落下、翻开顶刊、接过证书；视线——从成绩单抬起，扫过全班张大的嘴。
- **注**：涉及具体考试/排名请用虚构机构名，避免影射真实学校与真实人物。

### 8. 篮球（NBA / 国家队）
- **触发词**：篮球、NBA、总冠军、绝杀、扣篮、落选秀
- **世界观/基调**：总决赛抢七，最后一攻。
- **默认高光时刻**：终场前 0.8 秒后仰绝杀，哨响球进，全场炸裂，「我」捧起总冠军奖杯。
- **角色卡**：
  - 我：落选秀 / 被裁的双向合同球员
  - 崇拜者：队友、解说、满场观众、母亲
  - 对手：状元 / 曾隔扣羞辱「我」的球星
- **术语与道具库**：抢七、后仰跳投、绝杀、三双、盖帽、FMVP、总冠军、垃圾时间、更衣室、球馆顶棚
- **推荐场景**：球馆通道、罚球线、三分线外、篮下、领奖台、漫天彩带
- **经典金句**：`旁白（内心，喘着）：球脱手的那一瞬，整座球馆都屏住了呼吸。`

## 三、题材卡模板（未命中题材时现场推导）

复制以下结构，逐项填满即可：

```
### {题材名}
- 触发词：{用户可能说的词}
- 世界观/基调：{一句话设定 + 等级秩序}
- 默认高光时刻：{一个具体的、有画面感的仪式性瞬间}
- 角色卡：
  - 我（第一视角）：{起点身份，越卑微越好}
  - 崇拜者：{谁会仰望我}
  - 对手：{谁曾轻视我}
- 术语与道具库：{8-12 个该领域的真实术语/道具，用来给台词和场景加真实感}
- 推荐场景：{4-6 个具体地点}
- 经典金句：{一句 ≤ 20 字、回扣羞辱的内心独白}
- POV 细节钩子：{手部动作 + 视线翻转}
```

**推导要点**：
1. 起点必须有**明确的羞辱者**和**具体的羞辱场景**，不能只是"很惨"。
2. 高光时刻必须是一个**仪式性动作**（领/举/戴/敲/拜/跪），不能只是"成功了"。
3. 术语库越真越好——真实术语是沉浸感的来源，也是问答选项的弹药。
4. 高光时刻要能与起点"打脸"对应：起点谁踩你，高光就谁跪你。
