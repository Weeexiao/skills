# Toonflow 短剧剧本格式规范

本技能输出**必须**严格遵循本格式。格式源自用户提供的 `Toonflow短剧剧本模板.md`。
格式是骨架，**分镜设计感体现在 `△` 行怎么写**——写法规则见本文第四节。

---

## 一、骨架

```
1. {标题}

### 场1-1
{时间} {内|外} {地点}
出场人物：{角色A}、{角色B}
[音效：{音效1}]
[音效：{音效2}]
△ {分镜 1}
△ {分镜 2}
{角色A}（{情绪}，{语气}）：{台词}
旁白（内心，{情绪}）：{内心独白}
△ 卡点：{爆点描述}

### 场1-2
…
```

**"场"与"镜"的区别**：一场 = 一个时空单元（同一时间、地点）；一镜 = 一个 `△` 画面。60 秒片约 6-8 场、12-16 镜。

---

## 二、逐元素硬性规则

| 元素 | 写法 | 说明 |
|------|------|------|
| 标题 | `1. {标题}` | 序号从 1 起；标题 4-10 字，有画面感（如《敲钟人》《第九十八分钟》） |
| 场次 | `### 场{集}-{场}` | 单集剧本集号恒为 1：`场1-1`、`场1-2`…顺序递增 |
| 场景 | `{时间} {内\|外} {地点}` | 时间用：黎明/清晨/上午/正午/午后/黄昏/夜/深夜；内外只写 `内` 或 `外`；地点用 `·` 分层，如 `体育场·球员通道` |
| 人物 | `出场人物：A、B、C` | 中文顿号分隔；**POV 主角写「我」** |
| 音效 | `[音效：……]` | 方括号；每场至少 1 条，可多条 |
| 画面 | `△ {看的方式}——{看到什么}{正在发生什么}` | 见第四节，**这是分镜设计感所在** |
| 台词 | `{角色}（{情绪}，{语气}）：{台词}` | 全角括号 + 全角逗号 + 全角冒号 |
| 旁白 | `旁白（内心，{情绪}）：{台词}` | 仅用于 POV 内心独白；也可用 `旁白（画外）：` |
| 卡点 | `△ 卡点：{描述}` | 节奏爆点/反转/情绪顶点；每场最多 1 处，全片 ≥ 3 处 |

---

## 三、标点与禁忌

- 只用中文标点：`，。：、（）「」……——`；**禁用** `→ ● ■ ~~`（`·` 仅用于地点的层级分隔）。
- 台词**不加引号**（「」只用于标题或强调词）。
- 情绪与语气放全角括号内、用全角逗号分隔：`（震惊，失声）`。
- 不写"分镜表""导演阐述""镜头编号表"混进剧本正文。
- 不写纯文学的环境/心理描写；画面行只写镜头可感知的内容。

---

## 四、`△` 行：POV 分镜写法（设计感就藏在这里）

`△` 行不是小说句，**是一条分镜**。每条都必须回答：**镜头在哪、朝哪、怎么动、看到什么。**

**四要素公式**：`{看的方式}——{看到什么}{正在发生什么}`

| 反例（小说句，无镜头） | 正例（POV 分镜） |
|---|---|
| `△ 阿桃走过铁轨。` | `△ 主观下压，随脚步轻晃——一双草鞋踩过积水的石阶。` |
| `△ 巨魔的指节停在阴影边缘。` | `△ 视线定住，镜头屏息不动——阴影边缘，巨魔的指节一寸寸收住。` |
| `△ 他拿了奖杯。` | `△ 手部大特写——我的手握住冰冷的杯身，指节因用力而发白。` |
| `△ 全场鼓掌。` | `△ 镜头猛然后拉——从一张脸拉出满场起立的人海，掌声轰然盖过一切。` |
| `△ 主角很生气。` | `△ 镜头微微一沉，呼吸声变粗——前方的脸在视野里晃了一下。` |

**镜型词表**（写在 `△` 句首）：

`主观` / `主观微仰` / `主观俯瞰` / `主观侧偏` / `手部特写` / `手部大特写` / `脚部特写` / `前景肩影` / `视线摇` / `视线定` / `视线急甩` / `视线抬起` / `视线下压` / `镜头微推` / `镜头后拉` / `镜头骤稳` / `滑动变焦` / `手持微晃` / `固定` / `定格` / `背影`（全片 ≤2 次）

**三类镜配比**：A 主观镜 ≈80% ｜ B 身体镜（手/脚入画）≈15% ｜ C 背影抽离镜 ≤2 次。

**五幕的运镜策略**（详见 `references/pov-shot-design.md` 第三节）：
幕一 主观微仰＋前景遮挡＋手持微晃 → 幕二 视线定＋焦点转换 → 幕三 急甩＋**骤稳**＋滑动变焦 → 幕四 后拉揭示规模＋视线摇＋前景涌上手 → 幕五 手中物大特写＋视线抬起＋定格。

**`△` 行反面清单**（出现即改）：主角正脸/表情/全身；过肩镜；正反打；无来源光；与本场无关的空镜；主观镜里"我"回头看自己。

## 五、用户原模板（对照基准）

```
1. 桥下的巨魔

### 场1-1
黄昏 外 废弃铁路桥·桥面
出场人物：阿桃、巨魔
[音效：风穿过桥洞的低鸣]
△ 阿桃背着书包走过铁轨，脚步很轻。
△ 她摊开手，掌心里是半块压缩饼干。
阿桃（试探，声音发虚）：我吃不完。
巨魔（低沉，气声）：又一个。
△ 卡点：巨魔的指节停在阴影边缘，饼干滚进黑暗。
```

> 注：原模板是第三人称视角。本技能输出 **POV 第一人称版**：`△` 行按第四节公式改写，且画面内不出现主角。结构元素（场次、场景行、人物行、音效、台词、卡点）与原模板完全一致。

## 六、完整成品样例（本技能标准，都市创业 POV，60s，16 镜）

```
1. 敲钟人

### 场1-1
傍晚 外 写字楼·旋转门外
出场人物：我、保安、旧同事
[音效：下班人潮的脚步与说笑声，隔着玻璃门嗡嗡作响]
△ 主观下压，脚部入画，随脚步轻轻起伏——一双磨破后跟的旧皮鞋踩过地面积水。
△ 主观微仰，一截衣袖从镜头前划过——玻璃门内，旧同事抱着我的纸箱。
旧同事（轻佻，拖长音）：哟——走啦？
保安（不耐烦，命令）：工牌留下，别堵门。
△ 卡点：旋转门转过去，嘲笑声被关在门里。

### 场1-2
夜 内 出租屋·书桌前
出场人物：我
[音效：老式台扇的嗡鸣，键盘敲击声]
△ 手部特写——我的手把一张皱巴巴的名片拍在桌上：「星轨资本 合伙人」。
△ 视线定住，焦点缓缓收实，呼吸停了半拍——屏幕亮起那封邮件：「您的项目已进入终审。」
△ 卡点：台灯灭了，只剩屏幕的光映在墙上。

### 场1-3
日 内 路演厅·评审长桌
出场人物：我、评审席
[音效：空调低鸣，纸张翻动]
△ 主观微仰，手持微晃——一排评审的脸从长桌上方俯视下来。
评审（冷淡，打断）：下一个。
△ 视线落回桌面——我把文件推过去，对方的手停在半空。
△ 卡点：桌上水杯里的水纹，轻轻晃了一下。

### 场1-4
日 内 交易所·走廊
出场人物：我、工作人员
[音效：远处礼宾乐，人流的脚步由远及近]
△ 视线抬起——走道尽头，一排人同时转身望向这边。
△ 手持的晃动骤然静止——墙上电子屏：「星轨科技 上市首日」。
工作人员（恭敬，欠身）：先生，请。
△ 卡点：两侧的人齐刷刷弯下腰。

### 场1-5
日 内 交易所·敲钟台
出场人物：我、全场嘉宾、记者
[音效：掌声从稀落到轰然]
△ 镜头猛然后拉——从一张脸拉出满场起立的人海，闪光灯连成一片。
△ 视线摇过——一排排仰望上来的脸，每一张都朝着镜头。
△ 前景忽然涌上一片手——从画面下方伸上来，等着握我的手。
某嘉宾（激动，高喊）：星轨！
△ 卡点：一张熟悉的脸挤到最前面——那个旧同事。

### 场1-6
日 内 敲钟台·侧面
出场人物：我、旧同事、前老板
[音效：人声鼎沸中，一角忽然安静]
△ 视线停在那张脸上——他举着酒杯，手在发抖。
前老板（画外，压低）：当年……是我看走眼了。
△ 卡点：我的视线越过他们，落向台侧的钟锤。

### 场1-7
日 内 交易所·主厅
出场人物：我
[音效：钟声炸响，全场欢呼冲到顶点]
△ 手部大特写——我的手握住钟锤，一记砸下。
△ 背影抽离镜，全片仅此一次——侧后方，那道背对全场的身影；远处礼兵同时敬礼。
△ 视线抬起，俯瞰——整片起立的人海；漫天金色彩带里，画面定格。
旁白（内心，平静）：三年前那句「你不行」——今天，我替它敲了钟。
△ 卡点：彩带落满肩头。
```

**样例要点复盘**：
- 三类镜配比——A 主观镜 11 个 ｜ B 身体镜（脚/手）4 个 ｜ C 背影抽离镜 1 个（场1-7，全片唯一）。
- 主角全程零正脸：只有磨破的皮鞋、手、视线、背影。
- 运镜有动机：微仰（被俯视）→ 视线定（伏笔）→ **骤稳**（反转）→ 后拉（揭示规模）→ 视线抬起（加冕）。
- 他人全部望向镜头；台词 5 句、均 ≤15 字；卡点 7 处。
- 结尾定格 ＋ 回扣幕一羞辱的金句旁白。
