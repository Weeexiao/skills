# AI 短剧场景资产生成

为 AI 短剧设计和生成**空间一致的场景资产图**。把场景当作一个固定的三维空间而非四张独立插画，通过链式生成流程交付一张高分辨率 2×2 四宫格：

| 位置 | 视角 |
|---|---|
| 左上 | V1 · 正视图 |
| 右上 | V2 · 反向平视回望图 |
| 左下 | V3 · 45° 斜俯全景图 |
| 右下 | V4 · 90° 垂直俯视图 |

> 本技能用于场景资产，不用于角色设定图或单张无视角连续性要求的插画。

## 工作流程

1. **锁定场景圣经**：从场景描述中提取类型/时代/风格、固定结构、关键物件方位、光照方向等，作为全程不变的锚点。
2. **链式生成 V1 → V2 → V3 → V4**（不并行生成）：
   - V2 直接参考 V1；V3 直接参考 V2；V4 同时参考 V1、V2、V3；
   - 每一步验收后重试不合格步骤，上游出错则回退重生成受影响的下游视角。
3. **一致性检查**：结构恒等、方位闭环、光照闭环、风格恒等、镜头合规。
4. **拼接交付**：四张子图统一比例后拼合。

## 使用

核心规则与提示词规范见 [SKILL.md](SKILL.md)。

拼接四视角图：

```bash
python scripts/compose_grid.py 01-front.png 02-reverse.png 03-oblique-45.png 04-top-down.png \
  -o scene-asset-grid.png --cell-width 2048 --cell-height 1152
```

默认顺序为左上、右上、左下、右下，输出无缝无标签的高分辨率 PNG。
