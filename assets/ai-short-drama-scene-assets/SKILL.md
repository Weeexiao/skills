# AI短剧场景资产生成

把场景当作一个固定的三维空间，而不是四张彼此独立的插画。最终交付一张 2×2 四宫格：左上正视图、右上反向平视回望图、左下 45° 斜俯全景图、右下 90° 垂直俯视图。

## 开始前

从用户描述中提取并锁定一份“场景圣经”：

- 场景类型、时代、地域、时间、天气、视觉风格与色彩；
- 固定结构：墙、门窗、道路、台阶、柱体、地形等；
- 关键物件及其相对方位、朝向、距离、遮挡和尺寸关系；
- 主光方向、色温、阴影方向与实用光源；
- 不可改变项，以及允许模型合理补全的未知区域。

信息足以形成空间关系时直接执行。只有缺少会根本改变场景的关键信息时才询问用户。若用户已提供满意正视图，跳过生成但仍将其登记为第一视角基准。

图像生成或编辑必须使用当前可用的图像生成能力。每次生成前明确引用哪些既有图像；生成后检查结果，不能仅凭提示词假定一致。

## 核心规则

1. 严格按 V1 → V2 → V3 → V4 执行，不把四个视角一次性独立生成。
2. V2 直接参考 V1；V3 直接参考 V2；V4 同时参考 V1、V2、V3。
3. 空间一致性优先于画面美观。门窗、出入口、主体、关键道具和光源不得无故漂移、镜像、增删或换位。
4. 新视角只能补全此前不可见区域；已确认区域不得重新设计。合理补全一经接受，就写回场景圣经，成为后续固定事实。
5. 每一步验收后保留原尺寸文件，并用稳定命名：`01-front`、`02-reverse`、`03-oblique-45`、`04-top-down`。
6. 某一步不合格时回退到该步重做；若暴露出上游空间矛盾，则回到最早出错的视角修正，随后重生成所有受影响的下游视角。

## 生成链

### V1：初始满意场景图 / 正视图

生成正面平视、视觉清晰、可作为连续性基准的原始场景图。提示词应明确主体、环境、构图、镜头高度、风格、光线和需要清晰呈现的空间锚点。避免极端广角、鱼眼和会掩盖布局的景深。

验收：构图和氛围满足用户意图；固定结构与关键物件可辨认；没有明显结构畸变；足以支持反向推演。未达到“可作为绝对参考”的程度时，不进入 V2。

### V2：反向平视回望图

以 V1 为直接图像参考，把相机视为在同一空间中转身约 180°，保持相近的相机高度和镜头语言。提示词需包含：反向平视回望、补全相机背后和周围环境、延伸背景、保持同一场景的材质/光影/年代/天气，以及场景圣经中的空间锚点。

不要要求把 V1 的全部物体复制到画面中；只有从反向机位物理上可见的物体才应出现。用共同可见的结构边缘、出入口、光源或地标建立两图的对应关系。

验收：V1 与 V2 能解释为同一地点的相反朝向；共同锚点方位自洽；新增区域不与 V1 冲突；不存在无依据的镜像和物体漂移。

### V3：45° 斜角全景图

以 V2 为直接参考，从较高机位做约 45° 斜俯全景。使用 `45-degree oblique panoramic view`、`high-angle wide shot` 等表述；只有当视觉风格确实适合等距表现时才使用 `isometric view`，避免它把写实透视强制改成游戏式等距图。

明确保持建筑轮廓、关键物体坐标、朝向、距离和相互遮挡关系不变。扩大视野以解释 V1/V2 的空间联系，但不要借全景机会增加无关大型结构。

验收：主要物件的远近与左右关系可读；V1/V2 的相机方向在空间上能够成立；关键结构数量、尺寸比例和位置一致。

### V4：90° 垂直俯视图

同时引用 V1、V2、V3，以 V3 的整体布局为主、V1/V2 的立面细节为校验。要求相机光轴垂直地面：`90-degree top-down view`、`orthographic plan view`、`god's-eye view`、无倾斜、无地平线、尽量无透视畸变。

不可见的屋顶或遮挡物会妨碍布局时，可采用剖顶/移除顶棚的资产表达，但不得改变平面结构。人物若非空间标尺或用户明确要求，默认不加入。

验收：呈现标准化平面布局；墙体、通道、门窗和大型物件坐标与前三图一致；没有斜视、地平线或明显透视收缩。

## 一致性检查

拼接前逐项核对：

- 结构恒等：固定结构和关键物件没有增删、镜像、换位或尺寸突变；
- 方位闭环：V1 与 V2 的朝向相反，V3 能同时解释二者，V4 与 V3 平面坐标一致；
- 光照闭环：主光来源和阴影方向在相机变换后仍符合物理逻辑；
- 风格恒等：材质、天气、时间、年代、色彩和细节密度一致；
- 镜头合规：V1/V2 平视，V3 约 45° 斜俯，V4 严格 90° 顶视。

若图像能力不能稳定保持空间一致性，应明确说明局限，缩短提示词中的美学描述，强化锚点和坐标关系，再从最早失败步骤重试。不要用后期拼接掩盖视角逻辑错误。

## 拼接与交付

优先保持四张子图相同纵横比。比例不同时，以居中裁切填满统一单元格为默认；若不得裁切，则等比缩放并补边。统一分辨率与色彩模式，不拉伸图像。

可使用 `scripts/compose_grid.py`：

```powershell
python scripts/compose_grid.py 01-front.png 02-reverse.png 03-oblique-45.png 04-top-down.png -o scene-asset-grid.png --cell-width 2048 --cell-height 1152
```

默认顺序固定为左上、右上、左下、右下；输出无缝、无标签的高分辨率 PNG。用户明确要求时才添加分隔线或文字标签。交付时同时保留四张源图和总图，并简短记录任何由模型推断补全的区域。
