# 短视频传播结构观察库

本观察库用于避免故事板和分镜“信息完整但中规中矩”。它提炼的是短视频中常见的传播结构与视听共性，不是照抄爆款的文案、人物、镜头顺序或特效。秋拾方法库决定怎样拍、怎样剪、怎样配声音；本观察库补充判断“观众为什么会愿意点开、继续看、看懂并留下印象”。

## 使用原则

先选择一个与用户题材、账号调性和真实条件匹配的传播抓手，再用基础镜头组接与秋拾方法把它落地。不能为了留人而制造虚假冲突、恐慌、承诺、夸张反转或不兑现的结果。

短视频的“传播感”不等于快切。根据内容选择下列三种节奏密度之一：

- **信息密度**：教程、测评、产品、知识内容。每一组镜头都解决一个问题或补一条证据。
- **体验密度**：Vlog、探店、旅行、美食、空间内容。让观众先进入地点和感受，再看关键动作与变化。
- **情绪密度**：人物、剧情、治愈、成长内容。让视线、关系、停顿、反应和声音推动观看，不用空镜拖长情绪。

## 六种常见传播结构

### P01 未完成动作

**适用：** Vlog、体验、剧情、改造、制作过程。  
**开头抓手：** 第一镜从正在发生的关键动作、异常细节或临界结果切入。  
**镜头组：** 动作峰值/细节 → 人物或空间补足 → 关键节点 → 结果/反应。  
**秋拾结合：** QS-A02、QS-B06、QS-C01、QS-D03。  
**避免：** 动作看起来很大，但后面没有解释它与主题的关系。

### P02 结果先给

**适用：** 产品、教程、美食、改造、空间、前后对比。  
**开头抓手：** 先给可见的成品、变化、质感或关键卖点。  
**镜头组：** 结果特写/反差 → 真实对象或空间 → 过程关键节点 → 再次验证结果。  
**秋拾结合：** QS-A01、QS-A04、QS-B01、QS-B06。  
**避免：** 先说“效果很好”，但画面没有任何可验证证据。

### P03 真实需求或场景

**适用：** 小红书生活方式、探店、产品、旅行、知识经验分享。  
**开头抓手：** 人物在具体地点面对一个真实需求、选择或体验。  
**镜头组：** 人物 + 场景 → 对象/问题 → 选择/动作 → 可感知结果 → 经验落点。  
**秋拾结合：** QS-A01、QS-A03、QS-B01、QS-B05、QS-D01。  
**避免：** 只有漂亮环境，观众不知道人物来这里做什么。

### P04 反差或问题链

**适用：** 知识、产品、剧情、人物、改造。  
**开头抓手：** 用真实反差、限制或未解问题启动；画面同时给出一部分证据。  
**镜头组：** 反差/问题 → 证据或背景 → 解决动作/推进 → 结果 → 一句可回收的结论。  
**秋拾结合：** QS-A02、QS-A03、QS-C04、QS-D04。  
**避免：** 只靠夸张口播提问，后续没有回应。

### P05 感官进入

**适用：** 旅拍、空间、美食、治愈、情绪 Vlog。  
**开头抓手：** 先给有质感的环境声、触感细节、光线变化或人物进入空间的动作。  
**镜头组：** 环境/声音 → 局部质感 → 人物行动 → 关键体验 → 留有余味的出口。  
**秋拾结合：** QS-B01、QS-B04、QS-C05、QS-D01、QS-D02。  
**避免：** 把无关空镜连续堆放；每一镜都应让空间、关系或情绪更清楚。

### P06 关系或情绪变化

**适用：** 人物片、剧情、成长、品牌故事。  
**开头抓手：** 先给人物之间的距离、视线、一个未说完的动作或情绪状态。  
**镜头组：** 关系状态 → 动作/信息触发 → 细节或阻力 → 人物反应 → 新状态/余韵。  
**秋拾结合：** QS-A03、QS-B03、QS-B06、QS-C05、QS-D02。  
**避免：** 把情绪全交给音乐，人物和动作没有变化。

## 首屏与前 3–5 秒的镜头要求

首屏不一定要有口播钩子，但必须至少完成两项：

1. **看见什么**：主体、动作、对象或空间能被快速识别。
2. **为什么继续看**：有结果、问题、变化、体验、关系或可获得的具体价值。
3. **声音做什么**：环境声建立地点、动作声强调触感、音乐进入推动节奏；三者选其一或组合，不能只用通用 BGM 掩盖空画面。

前 3–5 秒之后，必须在后续镜头组明确兑现首屏承诺。开头若给结果，过程必须给证据；开头若给问题，后面必须回应；开头若给情绪，人物、关系或空间必须发生变化。

## 镜头组节奏的传播性检查

每一个镜头组输出前，检查：

- 这一组是否只推进一个清楚任务？
- 是否有“新信息 / 新动作 / 新情绪 / 新感官证据”之一，而非重复镜头？
- 景别变化是否有理由：空间、行动、细节、反应分别由谁承担？
- 相邻镜头是信息、动作、空间、视觉、声音还是情绪在连接？
- 关键动作是否保留足够时间，次要过程是否只保留节点？
- 声音是否与画面共同提供信息，而不是重复或掩盖？

## 输出要求

用户需要故事板、表格或完整制作包时，在项目开头列出：

`短视频传播抓手｜P 编号 + 具体抓手｜第一帧｜前 3–5 秒信息｜首段声音任务｜后续兑现镜头组`

当用户明确发布抖音或小红书时，再结合 [抖音与小红书内容开头参考层](platform-content-patterns.md) 校正为对应平台调性。用户未指定平台时，按题材和目标选择，不机械套用。

## 公开观察来源与边界

- 公开抖音内容中常见的开场讨论包括：认知冲突、明确收益、未解问题与结果前置；其价值在于“让观众有继续看的理由”，不在于复制句式。<https://www.douyin.com/video/7588915069746398900>
- 产品型短视频的公开讨论强调首屏快速呈现可见卖点；对应到分镜时，应先给产品或结果的画面证据，而不是只用口播。<https://www.douyin.com/video/7392173642362277158>
- 小红书公开指引强调笔记内容与核心搜索词、封面、视频、标题及正文的相关性；对应到视频，应让首屏对象与后续内容承诺一致。<https://fe.xiaohongshu.com/apps/vincent/barley?fullscreen=true&id=ba0aee82139d40739ee31731406736b6&naviHidden=yes>
- 小红书的倒金字塔设计原则支持重要信息前置，但它不是短视频完播率数据，不能被误写为平台算法结论。<https://rpdc.xiaohongshu.com/52-design-principles/inverted-pyramid>

本观察库于 2026-09-09 建立。它不是统计学意义的全平台爆款数据集；后续只有在取得可逐镜核对的公开视频、链接或用户授权素材时，才将新样本补入具体题材的案例图谱。
