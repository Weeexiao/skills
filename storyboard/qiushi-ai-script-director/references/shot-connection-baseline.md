# 基础镜头组接与视听判断

这是一套所有创意交付都要先过的基础判断。它不替代秋拾方法库；秋拾方法用于根据题材、条件和表达目的做出更具体的选择。先让镜头之间成立，再调用具体方法。

## 先定镜头组，再写逐镜

每个镜头组先写清四件事：

1. **段落任务**：这一组只推进什么信息、动作、关系或情绪。
2. **观看顺序**：观众先看到什么，再理解什么，最后得到什么变化或出口。
3. **景别分工**：需要空间关系时给远/全景，需要行动时收至中近景，需要触感、选择或情绪时给特写；不是机械地“远中近”轮流排。
4. **动作链**：重要动作保留起势、受力/关键点、结果；次要过程只留下能交代变化的节点。

若一个镜头组没有新的信息、动作或情绪变化，就删减、合并或重写；不能用重复姿势、装饰性空镜或无意义特写凑镜头数。

## 相邻镜头必须有可解释的连接

两个镜头之间至少有一种真实的连接依据，并在“剪辑/转场”栏写出实际切法与切点：

- **因果/信息连接**：上一镜提出对象、问题或动作，下一镜给回应、结果或补充。
- **动作/动势连接**：在动作最明确的瞬间切，下一镜延续同一动作方向、视线或节奏。
- **空间连接**：先建立空间，再进入局部；场景变化后需要时用环境、门、路、交通或人物进入重新定向。
- **视觉连接**：形状、颜色、构图位置、遮挡或运动方向相似，才使用匹配或遮挡转场。
- **声音连接**：环境声建立空间；下一镜有辨识度的声音可以先入；重音只卡真正有力量的动作峰值。
- **情绪连接**：人物反应、停顿、空镜或音乐变化承接前后情绪，且前后要有明确关系。

没有合理连接时可以硬切，但要写明硬切服务什么信息或节奏；不能为了“高级”强行使用转场。

## 节奏与声音的基础判断

- 需要观众看懂、学会或感受关键动作时，保留足够时长与声音细节；不要一律快切。
- 过程次要但必须交代时，保留开始、关键节点、结果，用快切压缩重复时间。
- 同机位动作过长时，可删去中间无效时间；跳切之后仍要让观众看懂动作已发生的变化。
- 每个段落至少判断一次：是由环境声、动作声、音乐、旁白还是安静承担观看重点；音效不能替代画面信息。

## 交付前的组接检查

在输出故事板、Excel 分镜或完整制作包前逐项确认：

1. 每个镜头组只有一个清楚任务，且有开始、推进、结果或出口。
2. 每个镜头都带来新信息、动作变化、情绪变化或明确的节奏功能。
3. 相邻镜头的方向、视线、动作和空间关系不会让观众迷失；如故意打断，已写清原因。
4. “剪辑/转场”写的是实际剪法和切点，不是方法编号或空泛词。
5. 画面、剪辑、声音各自有任务，并共同服务当前段落；没有把秋拾方法编号当作视听判断的替代品。
