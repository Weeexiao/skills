# 重点视频视觉参考卡｜产品、广告与空间

本卡从可读取的秋拾教学视频、原片与长教程中保留了压缩关键帧。它补足文字证据里的“画面到底怎样组织”，不复制原视频。

## 使用边界

- `QVV-` 是内置关键帧的来源编号，关键帧时间是**教学视频或参考原片中的定位**，不自动等同于用户项目的时长，也不等同于秋拾对原片的逐秒判断。
- 下列“可迁移判断”只写入有对应秋拾文字证据的内容；只有画面、没有对应文字结论的案例，明确标为“视觉参考”。
- 生成商业片或空间片时，先按用户真实卖点、产品状态、场地、人物、预算重做；不能照搬品牌、剧情、人物或完整镜头排列。

## QVV-122D9994A2｜Tesla Model Y 60 秒产品片

- 关键帧：`keyframes/QVV-122D9994A2/contact-sheet.jpg`
- 画面可见：夜间行驶环境 → 单一功能特写（音响）→ 座椅使用状态 → 性能结果画面；功能信息与画面对象同步出现。
- 可迁移判断：产品介绍不要把所有参数堆在同一段。先给使用场景，再用一个产品细节回答一个功能，最后以可感知的结果/状态收束。
- 秋拾文字证据：`QSD-0134-001/002`（特斯拉片头的音效与音乐衔接）；`QSD-0120-001`（车从静止到启动的首尾呼应）。
- 适用：汽车、设备、数码等有“场景—功能—结果”链条的产品片。

## QVV-4744E6F0D6｜Samsung 产品生态片

- 关键帧：`keyframes/QVV-4744E6F0D6/contact-sheet.jpg`
- 画面可见：人物真实使用手机 → 屏幕圈选动作 → 电脑编辑/协同 → 产品组合定版；功能不脱离人物动作单独出现。
- 可迁移判断：数码功能的镜头应从“手做了什么”开始，再让屏幕变化或结果承接；关键触控、确认或切换点可交给短促、轻量的动作音效加强。
- 秋拾文字证据：`QSD-0092-001`（三星产品展示：手触控、圈选、确认动作与音效任务）。
- 适用：手机、软件、智能设备、办公工具。

## QVV-03040C89E0｜立顿《多彩》产品广告

- 关键帧：`keyframes/QVV-03040C89E0/contact-sheet.jpg`
- 画面可见：植物/颜色的感官引子 → 抽象圆形意象 → 杯中产品 → 人物饮用的情绪结果；不是一上来只摆包装。
- 可迁移判断：当产品与自然、口感、色彩或气味有关时，可用与卖点相关的感官素材进入，再通过方向、形状或动作把镜头推到产品；产品出现后需让观众看清关键使用动作。
- 秋拾文字证据：`QSD-0112-001`（前推至茶叶、近黑场硬切到茶包落入杯中，以两个升格镜头完整交代产品动作）。
- 适用：食品、饮料、香氛、生活方式产品。

## QVV-93D20041E3｜餐厅人气表达

- 关键帧：`keyframes/QVV-93D20041E3/contact-sheet.jpg`
- 画面可见：备料/出餐动作 → 满座空间 → 多人用餐关系；“人气”由画面状态证明，不依赖口播宣称。
- 可迁移判断：空间/门店片先选一个可验证结果作为重点，例如满座、排队、出餐效率或互动；再从准备动作、关键服务动作和人群反应分别取证。需要强调前后反差时，可在同一景别/角度下做状态变化。
- 秋拾文字证据：`QSD-0128-001`（准备原料、同景别空座到满座，直观表达人气）。
- 适用：餐厅、咖啡店、零售门店、活动空间。

## QVV-A3174C8CA4｜红酒产品展示教学

- 关键帧：`keyframes/QVV-A3174C8CA4/contact-sheet.jpg`
- 画面类型：教学画面，包含布光、人物、酒杯与产品细节的拆解；用于理解“人物/空间如何引向产品”。
- 可迁移判断：用人物背影或前景先制造层次，沿着稳定的动作方向进入产品；再以酒杯、液体、包装等质感特写完成产品收束。若没有稳定器，可用慢速手持、桌面滑动或静物转动替代，重点是运动方向能接住下一镜。
- 秋拾文字证据：`QSD-0003-752/754`（背影遮挡、稳定器全跟随 POV 转至酒杯特写、最后展示包装）。
- 适用：酒饮、礼盒、手作、质感型商品。

## QVV-355B6A965D｜新手产品视频全流程教学

- 关键帧：`keyframes/QVV-355B6A965D/contact-sheet.jpg`
- 画面类型：秋拾讲解、实际拍摄与剪辑时间线，作为“从想法到成片”的视觉证据。
- 可迁移判断：产品片的快慢由信息任务决定：痛点或场景切换可短，笑点、使用、操作和关键卖点要留观看时间；剪辑的目标先是让人舒服地看懂，再少量使用效果加强。
- 秋拾文字证据：`QSD-0152-001/002/003`（从文案转镜头、快慢穿插、产品多角度/状态变化、效果适可而止）。
- 适用：零基础产品片、实拍分镜、AI 产品视频的动作/状态设计。

## QVV-DDD5710E51｜民宿/空间全流程教学

- 关键帧：`keyframes/QVV-DDD5710E51/contact-sheet.jpg`
- 画面类型：秋拾讲解、设备和时间线，配合文字证据理解空间短片的素材分工。
- 可迁移判断：空间片先把素材分成开头、文案对应、过渡和结尾四类；场地小也要以景别、物件、人物动线和声音层级建立空间感。文案说到什么，就给能证明它的真实画面，不用空泛景别堆砌。
- 秋拾文字证据：`QSD-0149-001/002/003`（民宿全流程、文案与素材对应、两层声音与完整素材分工）。
- 适用：民宿、酒店、餐厅、展厅、住宅、工作室等空间片。
