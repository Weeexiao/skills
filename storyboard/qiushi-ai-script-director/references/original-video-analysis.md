# 原片拉片规范

## 适用情形

用户上传或明确提供一支原片，要求“拉片”“逐镜拆解”“把原片做成带截图的脚本”时使用。原片是主要证据，最终交付为 Excel 拉片表。

## 工作流程

1. 先读取视频的时长、画幅、帧率和是否包含音轨。视频不可访问时，请用户重新上传或提供本地路径。
2. 使用 [逐镜截图工具](../scripts/extract_video_shots.py) 初步检测切点并提取每镜截图与时间码。自动检测只生成候选镜头，必须人工/视觉复核。
3. 重点检查自动切分容易漏判或误判的部分：叠化、淡入淡出、遮挡转场、速度变化、分屏、同一镜头内的快速摇移，以及声音先入或滞后。
4. 逐镜只记录原片中真实可见、可听见的内容。画面以外的镜头焦段、灯光器材、拍摄动机、音乐版权等，不能臆测；有合理推测时清楚标为“推测”。
5. 用电子表格创作工作流完成嵌图、渲染检查与 `.xlsx` 导出。

超过约 250 镜或片长超过 10 分钟时，先告知用户将按段落分批处理或确认是否只分析指定区间；不要为了赶时间跳过镜头截图。

## Excel 工作表

### 1. 影片总览

记录片名/文件名、总时长、画幅、帧率、是否有音轨、总镜头数、题材、整体叙事结构、节奏/情绪变化与拉片重点。

### 2. 逐镜拉片

冻结表头、启用筛选、自动换行，逐镜一行并按时间顺序排列。

| 列 | 字段 | 填写要求 |
| --- | --- | --- |
| A | 镜号 | 从 1 连续编号 |
| B | 原片截图 | 本镜的实际截图，嵌入本行 |
| C | 起始时间 | `mm:ss.S` |
| D | 结束时间 | `mm:ss.S` |
| E | 时长（秒） | 数字，等于结束减起始 |
| F | 画面内容 | 真实发生的画面、人物动作与信息 |
| G | 景别/构图 | 画面中能判断到的景别、主体位置、前中后景、视线 |
| H | 机位/运镜 | 固定、推拉、摇移、跟拍、手持等；无法判断则说明 |
| I | 剪辑/转场 | 硬切、叠化、遮挡、淡入淡出、匹配剪辑等 |
| J | 文案/同期声 | 可听清的旁白、对白、同期声；听不清则标注 |
| K | 音乐/音效 | BGM 进入/停顿/变化，环境声和效果声 |
| L | 色彩/情绪 | 可见色调、光线感觉及镜头承担的情绪任务 |
| M | 拉片要点 | 这镜为什么在这里、怎样服务结构或信息 |
| N | 可复用方法 | 新手可迁移的拍摄、剪辑或声音做法；保持原创边界 |

截图保持原始画幅比例，行高足够显示，且不覆盖邻行。截图数必须与镜头行数一致。

### 3. 结构拆解

列为 `段落｜时间范围｜镜号范围｜叙事/信息任务｜视听策略｜节奏/情绪变化｜值得学习的方法`。按开场、推进、转折/看点、结尾组织，不强行套固定段数。

### 4. 可复用方法

列为 `方法编号｜对应镜号｜类别｜原片证据｜可迁移原则｜新手简化做法｜注意事项`。类别可为开场、构图、运镜、转场、声音、文案、调色或节奏。

## 交付检查

- 镜号连续；起止时间递增；时长为数值并与时间差相符。
- 每镜都带实际截图，截图清晰且正确对应时间段。
- 逐镜拉片的图片、文字、时长和声音栏不被裁切；工作表已进行渲染检查。
- 不建立或交付“封面”文件夹；发布封面不属于拉片学习资料。
