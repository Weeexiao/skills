# Excel 交付规范

## 交付原则

本规范只适用于 B、C、D 模式的 `.xlsx` 交付。A｜故事板预览只交付故事板总览与逐格说明，不建立工作簿。B｜表格分镜默认不要求原创草图；C｜完整制作包才要求所有可执行信息和原创草图放在同一本工作簿中。

使用电子表格创作工作流生成工作簿；生成后检查关键单元格、嵌入图片和渲染结果，再导出到用户可访问的输出目录。

## 工作表

## 写表前的镜头组接检查

在填写“分镜脚本”前，先按 [基础镜头组接与视听判断](shot-connection-baseline.md) 完成镜头组设计。逐镜表不是把好看的镜头逐行堆放：每个段落应先明确观看顺序、景别分工、关键动作链和声音任务；J 列再写每次真实的连接方式与切点。秋拾方法编号只放 K 列，不能替代这些判断。

### 1. 项目总览

在顶部放项目名与生成日期。以下信息按“标签｜内容”排列：创作目标、受众/发布平台、画幅、目标时长、已有素材/人物/场地、器材与时间限制、必要假设、整体结构、预计镜头数。用户指定抖音/小红书或首屏目标时，额外写一行 `平台首屏策略｜第一帧画面 + 前 3–5 秒信息 + 声音任务 + 后续兑现位置`；策略必须符合 [抖音与小红书内容开头参考层](platform-content-patterns.md)，且不能覆盖真实拍摄条件与镜头组接判断。用户目标为短视频传播时，额外写一行 `短视频传播抓手｜P 编号 + 具体抓手 + 第一帧 + 前 3–5 秒信息 + 首段声音任务 + 后续兑现镜头组`，并按 [短视频传播结构观察库](short-video-transmission-patterns.md) 自检。

### 2. 分镜脚本

冻结首行、启用筛选、自动换行。逐镜一行，列顺序固定如下：

| 列 | 字段 | 填写要求 |
| --- | --- | --- |
| A | 镜号 | 从 1 连续编号 |
| B | 段落/叙事任务 | 开场、信息推进、情绪转折、结尾等 |
| C | 原创草图 | C 模式或用户明确要求“带图”时嵌入且只对应本行镜头的原创分镜草图；B 模式可省略此列或标为“未要求”。 |
| D | 画面与构图 | 场景、人物位置、景别、前中后景 |
| E | 拍摄方式 | 机位、运镜、角度、光线与器材提醒 |
| F | 人物/画面动作 | 镜头内发生什么，服务什么信息或情绪 |
| G | 时长（秒） | 数值；总览页汇总总时长 |
| H | 文案/同期声 | 旁白、对白或明确的无台词说明 |
| I | 音乐/音效 | BGM 的进入/变化、环境声、音效、声音先入等 |
| J | 剪辑/转场 | 只写实际剪法 + 切点/连接依据，例如“硬切｜关门动作峰值切入车内”“遮挡转场｜门框完全遮画后切室内”“动势匹配硬切｜上升接上移”。禁止填写 `QS-` 方法编号。 |
| K | 秋拾方法依据 | 填“QS-编号｜短名称”，例如“QS-A01｜地点+人物/动作；QS-B04｜人小环境大表达情绪”，关联“秋拾方法依据”工作表。 |
| L | 拍摄准备/替代方案 | 道具、预拍素材、素材不足时的可拍替代法 |

当交付包含草图时，“原创草图”列要足够宽；每个镜头行高至少能完整显示其 16:9 或 9:16 草图。草图尺寸保持比例、不裁切、不覆盖其他行。C 模式的草图数量须与镜头数一致；B 模式未要求带图时不以草图数量为交付门槛。

### 单场景故事板附加工作表：故事板总览

仅在 C 模式中，且用户需要 6 宫格、9 宫格、单场景故事板或关键帧总览时新增，放在“项目总览”之后。A 模式不建立工作簿，直接交付故事板总览和逐格说明。

- 顶部写明：用途（实拍 / AI 生成）、场景任务、开始状态、关键变化、结果/出口、格数选择理由与必要假设。
- 嵌入一张按镜号顺序合成的 3×2 或 3×3 黑白 / 低饱和手绘草图总览；总览的每格必须来自独立生成并通过连续性检查的草图，不接受一次生成的多格漫画。
- 总览下方列出“本场景秋拾判断依据”：方法编号、方法名称、适用条件、本项目改写、内置案例证据。没有直接可参考的方法时，单列“原创补充设计”，不伪造编号或案例。
- “分镜脚本”工作表仍逐格一行，草图数量必须等于 6 或 9；实拍版在 L 列给低成本替代，AI 生成版在 L 列写每格提示词/连续性锚点或另加“AI 提示词”列。

### 3. 秋拾方法依据

默认列出 `方法编号｜方法名称｜适用条件｜具体做法｜本项目改写｜内置案例证据`，至少两条。方法编号须来自内置秋拾方法库，且只能列出真正用于本项目的方法。“内置案例证据”逐条抄录方法库内已有的 `案例编号｜文件名｜工作表:行号`，不写任何卖家电脑路径。用户额外上传参考材料时，才追加 `用户提供参考名称｜镜头/镜头组｜实际观察到的证据` 三列；不要虚构案例名称、镜号或画面证据。

### 4. 拍摄清单

按 `类别｜事项｜对应镜号｜优先级｜备注/替代方案` 列出人物、场地、道具、器材、必拍素材与后期素材。让新手能在拍摄前打勾准备。

## 格式与检查

- 工作簿整体用简洁、清晰、适合打印和片场查看的样式；表头突出，避免花哨大面积色块。
- “分镜脚本”按段落用柔和底色区分；图片列和文字列都有边框，长文本换行。
- “时长（秒）”使用数字类型；“项目总览”中总时长应由分镜表的时长列汇总，不能手填为无法核对的数字。
- 导出前检查：镜号连续、图片数量等于镜头数、总时长正确、方法编号可回查、没有空白草图、关键文字未被裁切；J 列没有任何 `QS-` 编号，K 列每个编号均带短名称并能在“秋拾方法依据”工作表查到完整说明。
- 对每个工作表至少进行一次视觉渲染检查，修正图片遮挡、行高不足、列宽过窄或表头不可见的问题。B 模式重点检查表格的可读性和字段完整性；C、D 模式还必须检查嵌入图片。
