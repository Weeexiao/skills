# MiniMax H3 电影分镜导演

一个专门用于设计电影化分镜和 MiniMax H3 Ref2VA 提示词包的技能，可将剧本转换为两种交付物：供人审阅的中文电影分镜规格书，以及可直接用于 MiniMax H3 全能参考模型的英文六段式提示词。

## 核心功能

### 🎬 电影分镜设计
- 基于剧本创建详细的电影分镜规格书
- 遵循物理可行性、叙事情绪和视觉多样性的优先级
- 包含完整的镜头语言目录：景别、焦段、机位、运镜、景深、纵深、构图等

### 📝 H3提示词生成
- 生成符合 MiniMax H3 Ref2VA 格式的六段式提示词
- 人工分镜默认无时间轴；执行提示词保留当前接口要求的切点或帧对齐
- 包含完整的参考素材声明：`<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`

### 🎭 表演指导
- 电影化表演指导：把台词写成行为结果
- 群像分级管理：A档（全景及以上）和B档（近景/特写）
- 情绪曲线设计：标注情绪类型、强度、状态和节点

## 工作流程

1. **锁定剧本事实** - 建立角色、场景、道具、台词和动作清单
2. **预可视化空间** - 为每个场景标注空间类型、面积感、层高、门窗等
3. **画情绪曲线** - 设计情绪节点和切镜点
4. **设计中文分镜** - 创建详细的电影分镜规格书
5. **声明H3参考素材** - 按顺序声明所有参考素材
6. **按实际工作流编写提示词** - 全能参考六段，歌曲数字人普通动作正文
7. **审查并修复** - 逐字核对台词，逐镜检查连续性

## 使用场景

### 📖 剧本分镜设计
```
用户：为这个剧本片段设计电影分镜
技能：分析剧本 → 预可视化空间 → 设计分镜 → 生成H3提示词
```

### 🎬 H3提示词优化
```
用户：优化这个H3提示词
技能：检查格式 → 分析镜头 → 优化运镜和表演 → 生成优化版本
```

### 🔍 分镜审查
```
用户：审查这个分镜包
技能：逐字核对台词 → 检查连续性 → 验证运镜约束 → 输出审查报告
```

## 与h3-prompt-optimizer的协同

本技能与 `h3-prompt-optimizer` 技能形成完整工作流：
1. **minimax-h3-storyboard-director**：从剧本设计分镜和H3提示词
2. **h3-prompt-optimizer**：优化提示词，应用《小墨个人分镜SKILL6.0》规则

### 核心规则
1. 不在分镜或H3提示词中标注时长、秒数、时间码
2. 剧本台词逐字保留，不删、不改、不合并
3. 物理可行性 > 叙事情绪 > 视觉多样性
4. 每个镜头必须标注运镜方式
5. 每镜必须同时标注景深策略和纵深主层机制

### 运镜约束
- 全片固定镜头不得超过镜头总数的30%
- 每个对话段落至少包含一个运动镜头
- 整组分镜以六种不同运镜为最低多样性目标
- 重技法镜头需要三重确认：叙事理由、重锤资格、使用次数

### 质量标准
- 光学清晰，高光柔和滚降，中间调密实
- 真人皮肤保留毛孔、细纹、小瑕疵
- 焦外来自真实镜头与景深
- 色彩按综合色盘、饱和度、胶片基底、颗粒和光晕描述

## 工作流与提示词适用范围
