# 输出模板与审查

## 中文分镜模板

人工审阅默认不写时长字段；实际工作流要求的帧对齐和切点在执行提示词中保留。

```markdown
### 镜头 01｜镜头功能
【场景空间】空间分类、面积感、层高、门窗与机位区
【在场角色与站位】用门、窗、桌、柜等锚点描述
【群像管理】A档：总人数及逐人位置动作；B档：当前主体及背景处理
【镜头类型】人物镜头／非人物镜头及其叙事作用
【画面内容】正在发生的瞬间；多主体先写视觉中心
【景别／焦段】中全景／35mm
【机位／构图】平视／框架构图
【景深策略】浅景深／深景深／焦点转换，三选一
【纵深主层机制】光／曝光分离、随距离衰减的大气透视、遮挡／尺度递退，三选一
【运镜方式】路径、速度变化、稳定性或晃动幅度、停止点及叙事目的
【重技法确认】仅重技法镜头填写：叙事理由／本场重锤资格／本场与全片使用次数
【光影设计】光源锚点、方向、软硬、色温和阴影
【色调与质感】综合色盘、饱和度、摄影锚点、颗粒与光晕
【人物表演】视线、呼吸、表情前兆、微动作和余韵
【台词与声音】说话人；画内或画外；原文；动作声与环境声
【衔接】硬切或匹配方式；站位、背景与轴线延续
【镜尾状态】人物位置、左右手占用、道具数量与状态、动作完成度、光线和跨镜声音
```

## 片段包顺序

片段名称与功能、中文分镜故事板、参考素材清单与上传顺序、匹配当前模式的 H3 提示词、必要的参考音色映射、连续性与风险说明。故事板和参考图数量遵守当前项目限制。只出场一次且无需固定音色的角色不强制提供参考音频。

## 台词审计

- 每句台词都出现且只出现一次；字词、标点、顺序和说话人保持原文。
- 分拆长台词后可拼回原句；`(Sx)` 与 `<Audio N>`、`<Subject N>` 绑定一致。
- 切到听者时，画外台词仍属于原说话人；听者嘴唇闭合并作具体反应。
- 没有擅自添加旁白、字幕、口号或画面文字。

## 画面审计

- 场景已分类；镜头在物理空间内可实现；每镜均标注运镜方式。
- 固定镜头占比不超过 30%；没有连续三个固定镜头；每个对话段落至少一个运动镜头。
- 整组分镜使用至少六种运镜；若空间不足，已说明并覆盖可行的有效类型。
- 每个重技法已记录叙事理由、重锤资格、本场次数和全片次数，且未超过上限。
- 每镜均标注一种景深策略和一种纵深主层机制，整片景深策略有变化。
- 大气透视只用于外景或大尺度远景；体积光同时具有可见介质和具名光源。
- 所有前景元素来自场景或原文，具有自然的机位关系。
- A档镜头明确总人数及逐人站位动作；B档只锁主体，切回A档时恢复仍在场人物。
- 三人及以上场景的A档群像覆盖率已检查；人物被裁切与真正离场已区分。
- 对话先建立空间关系且至少有一个双人同框；面部近景和特写默认不超过40%。
- 非人物镜头以30%–50%为目标区间，连续四个人脸镜头已检查；必要性优先于比例。
- 长台词切镜已优先考虑物件、局部肢体、环境、光影和反应局部，没有凭空增加道具。
- 每场有内部情绪曲线；运镜速度、稳定性和幅度随情绪变化；每个重锤后有留白构图。
- 每镜的镜尾状态已进入状态账本，下一镜的人员、左右手、道具、动作、背景、光线和声音与之相容。
- 对话已建立空间、轴线和视线；人物数量稳定，无复制体。
- 进出场有动作依据；背景结构、家具、光源、时段和天气稳定。
- 人物身份、服装、发型、身材和年龄稳定；表演有前兆、微动作和余韵。
- 非人物镜头有实际作用；画面无时长、秒数、时间码或时间轴。

## H3 格式审计

- 已先识别工作流：全能参考六段；普通生成／首尾帧按对应三段；歌曲数字人普通动作正文，不混用。说明为英文，对白与画面文字保留原语言。
- 参考素材按上传顺序声明，编号稳定；保留分析说明强度和用途。
- 全能参考审阅版可用自然硬切语言；实际节点需要 Shot、时间码或首尾帧对齐时，已按真实时长表达且无互斥要求。
- 支持 H3 标签的模式中，每个实际说话人保持稳定编号；音色用 reference，完整音轨用 fully_copy，部分复制或混音用 partially_copy。歌曲数字人不强加标签，核准唱词与实际音频一致。已有歌曲保留原伴奏，不额外配乐。
